GitHub 出的 Spec-Driven Development（SDD）toolkit，把 specification 從「事前文件」提升為可執行、可生成的 first-class artifact——以 spec 為中心驅動 agent 生 code，改 spec 等於改 code。可跨 30+ agent host（Claude Code、Codex CLI、Copilot、Cursor、Gemini CLI 等）。社群認同「先講清楚再寫」方向，但多數團隊仍小規模觀望——評價與長期風險見 [[Spec-Kit-流程]]。
