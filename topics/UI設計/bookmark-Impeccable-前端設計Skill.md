Claude Code 與多個 AI harness 通用的前端設計 skill，用 curated anti-patterns 規則攔下 AI slop（過度卡片巢套、bento box、紫漸層、Inter 預設審美）。觸發情境：建立新介面（`craft`）、稽核既有設計（`audit`）、瀏覽器內 micro 微調（`live` 模式）。完整命令清單與涵蓋面向以官網為準。支援 Cursor、Claude Code、Gemini CLI、Codex CLI。
