BMAD Method（Breakthrough Method for Agile AI Driven Development）是以 agile lifecycle 為骨架的多 agent 開發框架，把軟體開發各種角色（PM、Architect、Developer、UX 等）做成 persona，從規劃到部署各階段切片接力跑 user story；可跨多個 agent host。實際 persona 數量與階段細節以官方 docs 為準。
