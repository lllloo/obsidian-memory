這些 skill 出自 [obsidian-skills](https://github.com/kepano/obsidian-skills)，由 Obsidian 共同創辦人 Steph Ango（GitHub 帳號 kepano）維護，讓 Claude Code 直接讀寫 vault 與處理網頁來源。本篇列目前實際安裝、日常會用到的 skills；其餘未安裝的候選項目見上方 repo。

| Skill | 用途 |
|-------|------|
| `obsidian-cli` | 透過 Obsidian CLI 讀取、建立、搜尋筆記，管理 tasks 與 properties |
| `obsidian-markdown` | 撰寫 Obsidian Flavored Markdown（wikilinks、callouts、embeds） |
| `obsidian-bases` | 建立與編輯 `.base` 資料庫視圖 |
| `defuddle` | 從網頁擷取乾淨 Markdown；`.md` 結尾的 URL 直接用 WebFetch |
