Google Labs 的 AI-native 軟體設計畫布，把設計發想、設計系統、變體探索、交給 coding agent 落地的流程串在一起。觸發情境：Claude Code 做前端時用來補足視覺發想（infinite canvas 探索方向）、產出 `DESIGN.md` 把設計規則帶進專案、用 Agent manager 平行探索多個方向。模型命名與 skill 清單會隨 UI / SDK surface 漂移，實作以當下官方為準；截至 2026-04 仍為 Beta。
