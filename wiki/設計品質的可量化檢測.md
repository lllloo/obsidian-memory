# 設計品質的可量化檢測

核心命題：**好設計沒有標準答案，但壞設計有標準訊號。** 配色、間距、圓角本身沒有對錯，同一需求給十個設計師會有十個各自成立的版本——這正是 AI 生成設計的根本難題：在沒有標準答案的領域，AI 只能回傳「訓練資料裡最不會出錯的平均答案」，於是產出都帶著一種「似曾相識、專業但無記憶點」的既視感，且常夾帶錯位、對比不足、字級不一致等說不出口的小毛病。

破解不需要成為設計師，而是換思路：設計被研究了約 70 年（眼動實驗自 1960 年代、Flesch 可讀性研究可追溯至 1940 年代、WCAG 累積二十餘年），這些「避開就至少不會太糟」的法則早已被寫成可跑的工具。AI 其實知道這些規則，但生成時遵守得不穩定；跑工具才知道哪裡漏了。

## 兩面向、四項可量化檢測

把網頁設計拆成**功能**（會不會出問題）與**視覺**（清不清爽）兩面向，各再拆成可量化的問題：

| # | 問題 | 工具 / 方法 | 抓什麼 |
|---|---|---|---|
| 1 | 眼睛先看到重點嗎？ | DeepGaze 類**眼動預測模型**：丟截圖→吐注意力熱力圖 | 重要元素（如主 CTA）是否落在**暗區**——打開第一秒根本沒被看到。關鍵不是整頁越亮越好，而是重要的亮、次要的暗 |
| 2 | 看得懂嗎？ | **可讀性**：Flesch-Kincaid 年級指標（中文無對應公式，改用 LLM 質化評估「這句太抽象」）；**無障礙**：WCAG，經 axe-core / Sa11y 自動化檢查 | 文案閱讀門檻過高（英文寫到 14 年級，一般人 3 秒關掉）；對比不足、連結說明模糊、圖片缺 alt——影響「能否理解內容」的硬門檻，非小事 |
| 3 | 看懂了會採取行動嗎？ | **AI agent 模擬使用者**：給一句任務指令（如「找到 Pro 方案月費」），讓它自己開瀏覽器、滾頁、點擊，回報成功/失敗與卡在哪一步 | 所有人都會卡的**結構性**問題：按鈕點不到、關鍵資訊藏在第三層導覽、CTA 被彈窗擋住。不能代表真實使用者，但能抓通則性卡點 |
| 4 | 整體一致嗎？ | **Playwright 讀取每個元素實際 CSS** 做統計 | 一個網站用了 47 種灰、13 種字級、15 種按鈕樣式——肉眼分不清十個相似灰該刪哪個，工具幾秒統計出來。**跨頁比對**尤其有用：首頁深灰、定價頁淺灰，差一點肉眼無感但大腦感覺得到，是設計系統沒落地最強的訊號 |

好看的網站幾乎都有共同點：**設計風格一致**（主色就一個綠、字級就六種、圓角就兩種）。雜訊越多，認知負擔越重，使用者說不出哪裡不對，就是覺得亂，然後離開。

## 閉環：報告 → AI 修正 → 重跑

四項工具串成閉環：對剛產出的頁面跑一遍 → 得到結構化報告（哪些元素有問題、類別、嚴重程度）→ 把報告交給 coding agent「根據這份報告給修正計畫」→ 它會指出「這顆按鈕對比不符無障礙、建議加深」「註冊按鈕落在視線死角、建議上移」→ 改完再跑一次，分數往上走。跑三到五輪，一個完全不懂設計的人也能不再照單全收 AI 的產出。

**這是「驗證迴路用 agent 改不到的外部判準」的具體實例**：眼動模型、WCAG 檢查、CSS 統計都是 coding agent 無法從內部造假滿足的客觀量測——正好對應 [[AI-自主工作流的實證檢驗]] 的結論「驗證那一步要用 agent 無法從內部滿足的判準，而非讓它自寫自測自驗」。四項中眼動、CSS 統計與 WCAG 自動檢查（第 1、4 項及第 2 項的無障礙子項）是獨立、可執行、非 LLM 自評的客觀量測；第 2 項的中文可讀性子項（英文用 Flesch-Kincaid 公式，中文無對應公式改用 LLM 質化評估）與第 3 項（AI agent 模擬使用者）則仍是 LLM 判斷、非純工具量測，其中第 3 項評的是**行為結果**（任務能否完成、卡在哪一步）而非讓生成方自評設計美學，屬與被測 agent 不同任務的獨立執行者，藉此**降低**（非完全消除，同模型家族時的殘留風險見下方「相關頁」）[[AI-自主工作流的實證檢驗]] 點出的 LLM-as-judge self-preference bias（該偏誤正是 [[Building-Effective-Agents-Anthropic]] 的 evaluator-optimizer 模式被檢驗出的證據邊界）。

## 邊界：工具止於及格線，品味定義偏離

這些工具的本質是**把設計推向平均**：對比不夠就拉高、字級太多就收斂、按鈕看不到就移進熱區。都對，但只能把設計推到及格線、消除明顯的壞偏離；**及格線之後是另一回事**。

「平均臉」實驗點破了工具的天花板：把數十張臉像素平均，得到的臉對稱、比例標準、無瑕疵，吸引力評分甚至高過多數原始臉——但沒人記得住，因為它不是任何一張真實的臉。而評分**最高**的臉不是最平均那張，是**朝某方向有選擇地偏離平均**的那張（稜角的下巴、稍大的眼睛）。正是那個偏離讓它難忘。工具給的是一份清單，不是答案；**哪些要修、哪些是故意要留的偏離，那個判斷叫品味，工具教不了。**

對應到設計工作的三層：

- **執行**（畫圖、寫 CSS、做 mockup）——AI 完勝，差距持續擴大。
- **評估**（判好壞、給方向、決定取捨）——工具能過濾壞偏離，但哪個偏離值得保留由人決定。
- **定義**（做什麼、為誰做、解決什麼問題）——只有人能做，需要的不是設計知識而是對人的理解。

含意：學設計的路徑從「由下往上」變成「可直接從中間開始」——執行層交給 AI，時間投資在評估與定義。這不是變輕鬆而是變難，因為畫圖有課程可上，品味沒有。越多人把設計完全外包給 AI，有品味的人越稀缺、越值錢。
