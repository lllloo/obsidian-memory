出門在外臨時想處理事情，卻卡在電腦留在家裡、手機難以打字也跑不了程式。Dustin 分享他怎麼做到「不帶電腦出門，也能用手機 / 平板指揮 Claude Code」，拆解他實際使用的兩種遠端方案，並反思「AI 該不該滲透生活每一刻」。

## 方法一：官方 Remote Control

最簡單、零設定，由官方維護。

- 前提：家裡電腦不關機、維持網路連通。
- 啟用：在電腦端 Claude Code（桌面版或終端機版）的現有對話中輸入斜線指令，選 Remote Control，按 Enter 後右下角會出現 Remote Control Active 標識。
- 手機端：安裝 Claude app、登入同一帳號，家裡的 session 就會自動同步過來，可在手機上繼續下指令。
- 同步範圍：訊息、工具呼叫、中間過程都即時雙向同步；可選不同模式（至少有計畫模式與兼顧安全與方便的自動模式，但選項比電腦版 / CLI 版略精簡）；支援語音輸入與附件 / 圖片。

### 限制

- 早期版本較陽春，不少內容沒同步過來，包括許多常用的內建 skill 與指令。
- 在手機上打對的指令 / skill 名稱仍會觸發，但沒有 CLI 或 App 版的聯想（自動補全）功能；skill 一多容易忘記名字，因此 Dustin 後來較少用此方案。

## 方法二：自建內網 + 手機模擬終端機（Dustin 主力方案）

核心組合：Tailscale 安全內網 + tmux 持久化 session + 手機模擬終端機 Moshi，透過通訊協定連回家裡那臺不關機的主機。因為這是終端機的完全對應，官方還來不及移植到 Claude app 的功能在這裡都不受影響。

### Moshi（手機端模擬終端機）

- 完整復刻終端機的內容與功能，畫面即時更新、時間高度同步。
- 有狀態列，可設 Ctrl / Escape / Tab 等熱鍵組合、方向鍵、滑鼠、語音輸入、開啟鍵盤。
- 高度自訂捷徑與按鈕，捷徑可支援 Claude Code、Codex、Cursor 等常用指令，按鈕觸發免打字，並支援手勢與語音辨識。
- 進階功能需付費，但 Dustin 認為便利性值得（聲明非業配）。Termius 是同類工具，可依個人偏好擇一。

### Tailscale（安全內網）

- 把各裝置（如 MacBook Air、iPad Pro、iPhone）串在同一私密內網。
- 串起後可走 SSH、Mosh 等通訊協定連線；新增連線有掃碼配對的懶人方式，熟設定者也可用自己的 SSH。
- 支援查看用量與通知模式：某個 session 完成任務、需要回應時，會在手機 / 平板跳通知。

### tmux（持久化 session）

- 讓終端機 session 持久化。遠端 / SSH 連線容易不小心斷線或關掉分頁，一般情況分頁關掉後 session 就救不回來。
- 裝 tmux 後，只要電腦不關機、不休眠，session 容器就還在；重新連回去文字與動作都還在，手機端同步狀態也保留。
- Dustin 目前讓 Claude Code 跑在 tmux 容器內，內含多個分頁（示範為三個，可再擴充）。

### 進階小細節

- 防休眠：在 Mac 用指令確保電腦不會休眠（影片未明示指令名稱）。
- 看檔案變更：Moshi 內建按鈕可檢視 git 哪些檔案變動、變動內容、推送分支、history，並提供小型瀏覽區。
- FileBrowser：透過內網瀏覽檔案的套件，登入後可像 Finder 一樣瀏覽資料夾與檔案，方便快速檢閱文件。
- 遠端桌面：當備胎，僅在真的需要在電腦上點按時才連入；因為太耗效能與耗電，不當日常操作方式。
- 工作時間配比：終端機 Moshi 是主力；約 20–30% 時間用 FileBrowser 瀏覽文件；不到 5% 時間需用遠端桌面在電腦上操作。

## 停電 / 斷網備援思路

不一定要做到極致，但可考量：

- 停電：裝智慧插座，偵測斷電後自動重啟。
- 斷網：確保路由器有遠端遙控自動重啟機制。

## 不推薦的方案

- Telegram / Discord / iMessage 連通：Dustin 試過覺得不合胃口，且觀察到 Anthropic 後來也沒積極維護，不建議當主力溝通形式。
- OpenClaw（影片稱「龍蝦」）：曾被許多分享者一致推崇，能在外讓它主動辦事、主動推送通知，但 Dustin 用後很快發現不適合自己。原因有二：一是它太自由、資安疑慮高（他也確實看到不少因操作不當導致資訊洩露甚至損失的案例）；二是它主打主動推資訊，但他希望工作與私人生活盡量分開。

## 反思：AI 該不該滲透生活的每一刻

Dustin 強調沒有哪種模式絕對好壞，重點是問自己「希望與 AI 的邊界在哪裡」。他希望與 Claude Code 協作時大幅提升效率，但平常沒事時不需要 AI 介入生活。這是 AI 發達時代要避免焦慮前必須思考的課題。
