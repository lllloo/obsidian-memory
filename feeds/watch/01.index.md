## 怎麼加/移除追蹤項

- **加**：在上表加一列，第一欄放 `owner/repo#num`（建議用連結 `[owner/repo#num](issue-url)`，skill 只認文字裡的 `owner/repo#num`）。issue 或 PR 皆可，skill 自動判別；PR 會辨識 merged/closed-unmerged。
- **移除**：刪掉該列即可；快照 `state.json` 內殘留項不影響，下次重建。
- **想追某 PR merge 了沒**：直接把該 PR 當一列追（比追「issue 的關聯 PR」乾淨可靠）。
