## GitHub Copilot

### 2026-07-31（[Gemini 2.5 Pro and Gemini 3 Flash deprecated](https://github.blog/changelog/2026-07-31-gemini-2-5-pro-and-gemini-3-flash-deprecated)）

**繁中摘要**：GitHub Copilot 自 2026-07-31 起於所有介面（Copilot Chat、inline edits、ask/agent 模式、程式碼補全）中棄用 Gemini 2.5 Pro 與 Gemini 3 Flash，已設定使用這兩個模型的工作流程需改選其他可用模型。

- **模型棄用**：Gemini 2.5 Pro、Gemini 3 Flash 全面退場，影響所有 Copilot 體驗，屬 deprecation 變更需留意既有設定。

### 2026-07-31（[Enterprise teams model policy targeting in public preview](https://github.blog/changelog/2026-07-31-enterprise-teams-model-policy-targeting-in-public-preview)）

**繁中摘要**：GitHub Enterprise（Copilot Business/Enterprise 授權）新增以使用者為單位的 model policy targeting 公開預覽，AI 管理員可針對特定使用者群組設定模型使用基準線，不再只能套用整個組織的統一政策。

- **細粒度模型政策**：管理員可依使用者/團隊差異化開放或限制特定模型，屬 billing/quota 治理相關變更。

### 2026-07-30（[GitHub Copilot in Visual Studio Code, July 2026 releases](https://github.blog/changelog/2026-07-30-github-copilot-in-visual-studio-code-july-2026-releases)）

**繁中摘要**：本篇彙整 VS Code v1.127 至 v1.131（2026 年 7 月間發布）的 Copilot 更新，聚焦與 agent 協作、變更審查、chat 與導覽體驗的改善。

- **Agent workflow**：多項更新針對與 agent 協作的流程優化。
- **Review 與 chat**：改善變更審查與 chat 導覽體驗，影響日常 VS Code 內 Copilot 使用流程。
