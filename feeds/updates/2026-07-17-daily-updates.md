## GitHub Copilot

### 2026-07-14（[GitHub Copilot for JetBrains expands BYOK capabilities](https://github.blog/changelog/2026-07-14-github-copilot-for-jetbrains-expands-byok-capabilities)）

**繁中摘要**：JetBrains 版 Copilot 大幅擴充 BYOK 與 provider 彈性，可接自訂 OpenAI-compatible endpoint 用自己的模型，並整合 Claude agent 自訂、內建 plugin marketplace 與本機 sandbox，全層級適用。

- **Custom endpoint（BYOK）**：可設定 OpenAI-compatible 自訂 endpoint 加 API key 使用自有模型，把 bring-your-own-key 彈性延伸到標準 provider 之外。
- **Claude agent provider**：支援 custom agents、skills 與 instructions，Pro 以上層級 public preview。
- **Plugin marketplace**：customizations 介面內建 marketplace，可直接瀏覽安裝 plugin 或從 source repo 安裝，不必跳外部頁面。
- **本機 sandbox**：JetBrains plugin 新增 local sandbox 設定流程，與雲端 sandbox 並存（preview）。
- **Chat 控制**：改善模型選擇與訊息重編輯，加速 prompt 迭代與多輪對話；另附 Copilot CLI 的 debugger skill，支援 agent 驅動的除錯流程（preview）。
