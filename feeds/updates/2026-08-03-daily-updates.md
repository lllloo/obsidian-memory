## OpenAI Codex

### 2026-07-31（[GPT-5.4 and GPT-5.4 mini retire from Codex on August 31](https://learn.chatgpt.com/docs/changelog#2026-07-31)）

**繁中摘要**：GPT-5.4 與 GPT-5.4 mini 將於 2026-08-31 從 ChatGPT 登入版 Codex 下架，需改用替代模型。

- **模型退場**：GPT-5.4 → `gpt-5.6-terra`，GPT-5.4 mini → `gpt-5.6-luna`，8/31 起 ChatGPT 登入的 Codex 工作階段不再可選舊模型。
- **API 使用者不受影響**：透過 OpenAI API 或 API key 驗證的工作階段仍可繼續使用 GPT-5.4／GPT-5.4 mini。

---

### 2026-07-30（[Browser upgrades, multi-repository review, and image editing 26.727](https://learn.chatgpt.com/docs/changelog#2026-07-30)）

**繁中摘要**：ChatGPT 桌面版（含 Codex）26.727 新增跨多個 repository 的程式碼審查介面，另有瀏覽器與圖片編輯功能更新。

- **跨 repo code review**：現在可在單一審查介面中檢視、審查跨多個 repository 的變更，不需切換視窗逐一審查。
- **其他更新（非 Codex 專屬）**：桌面版瀏覽器可搜尋 Google 與回溯瀏覽紀錄；圖片編輯新增聚焦與畫布檢視模式。
