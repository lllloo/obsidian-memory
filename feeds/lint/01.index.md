vault 健檢的設定與說明。由 `vault-lint-daily` skill 維護一份**待處理清單** `BACKLOG.md`(去重後留未解決項,解決即移除,取代舊的每日快照報告 `<YYYY-MM-DD>-lint.md`);**機械可修項(可唯一對應的死連結、index 漏登)自動修,需判斷與語意項進 BACKLOG——語意項只報告**,修補由使用者另行指示。本資料夾不屬三層系統:不 ingest、不 query、清單本身不 lint。

## 設定

- `semantic_days: 7` — 語意層只審近 N 天有 git 變動的 wiki 頁
- `semantic_page_cap: 10` — 語意層單次最多審幾頁，超過取最近變動者並在報告標注截斷
