vault 健檢日報的設定與說明。日報由 `vault-lint-daily` skill 產出（`<YYYY-MM-DD>-lint.md`，按日一檔，寫完即凍結）；**機械項（可唯一對應的死連結、index 漏登錄）自動修並在報告記錄，語意項只報告**，修補由使用者看報告後另行指示。本資料夾不屬三層系統：不 ingest、不 query、報告本身不 lint。

## 設定

- `semantic_days: 7` — 語意層只審近 N 天有 git 變動的 wiki 頁
- `semantic_page_cap: 10` — 語意層單次最多審幾頁，超過取最近變動者並在報告標注截斷
