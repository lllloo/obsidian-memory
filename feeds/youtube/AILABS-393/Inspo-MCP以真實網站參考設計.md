## 為什麼 AI 設計的網站看起來都很通用

- 模型在訓練時學到出現頻率最高的設計模式，並把它們視為「最安全」的選擇；prompt 缺乏設計方向時就回到這些模式。
- 每個模型都有自己的招牌風格，例如白底配紫／藍色，或暖橘配奶油色；看多了就會被認出是 AI 產物。
- 既有的設計 skill（如同作者的 Hallmark）會給模型設計方向、列出要避開的常見模式，部分還附熱門網站作參考。
- 共同缺口：這些參考與指示多以 markdown 文字描述，模型能讀到字型、版面安排，卻無法想像所有元件組合起來的樣子，也不理解網站需要哪種設計，只照指示清單去做。

## Inspo 是什麼

- 一個 MCP server，讓 coding agent 直接取用真實網站，而不只是設計指示；免費、不需帳號或 API key。
- 資料內容：
  - 832 個網站、2,320 張擷取頁面圖。
  - 同時有桌面與行動版截圖，讓 agent 看得到版面如何適應小螢幕。
  - 個別區塊參考（如導覽列、pricing 區塊），並可取得該區塊的程式碼。
  - 每個網站都附一份 `design.md`：結構化描述設計，含精確色值的配色、確切字型，以及文字大小、間距等量測值。
- 官網 landing page 可瀏覽收錄網站，並可連回原站。

## 運作方式

- agent 收到 prompt 後，透過 `recommend` 工具把需求描述送給 Inspo。
- Inspo 搜尋擷取頁面、檢視最接近結果的版面安排，選出前幾名中最常見的 layout，回傳最多 5 個採用該 layout 的範例。
- 同時回傳相符的元件參考、建議配色，以及最多 3 張截圖，讓 agent 實際「看到」設計組合起來的效果。
- 搜尋篩選條件：產業、頁面 layout、亮／暗主題；可在 prompt 中指定方向，agent 會用篩選縮小範圍。
- 找到合適參考後，agent 再請求那些頁面的細節與 `design.md` 才開始建置。
- Inspo 會要求 agent 只深入研究少數幾個參考：每多一次搜尋就多塞一批結果進對話，模型反而難以決定採用哪種風格。

## 安裝

- 從官網複製安裝指令貼到終端執行；安裝器會自動偵測已安裝的 coding agent，詢問是否全部加入。
- 目前互動流程無法只選單一 agent，回答 no 會直接取消整個安裝；要只裝到特定 agent，需在安裝指令加上 client flag 並指定 agent 名稱。
- 安裝在 user scope：在任何資料夾開啟 agent 都能用，不限於安裝時的專案。
- 裝完重開 agent，執行 MCP 指令即可看到 Inspo 與其 15 個工具。

## 實測：時尚品牌 landing page

- prompt 中要求 agent 先提供幾種風格讓使用者挑選再動工——不是必要，但能在整站建完前就攔下方向錯誤。
- 即使 prompt 沒明說要用 Inspo，agent 仍自動呼叫了這個 MCP。
- agent 不會原封不動轉送 prompt，而是先補上與風格相關的關鍵字再搜尋，對描述不夠具體的 prompt 特別有幫助。
- 它比對回傳參考的共同模式，歸納出屬於該風格的設計選擇；此例共研究約 24 個網站。
- 給出 3 個設計方向與說明，選定後開始建置。
- 成果與單純用模型（即使搭配設計 skill）明顯不同：首屏用圖片而非模型慣用的滿版大字，採粗體字型與符合主題的中性色。
- 檢查是否抄襲：請 agent 列出參考網站，逐一比對後發現彼此風格各異、成品沒有照抄任何一個——hero 區取自一站、按鈕取自另一站、商品排列取自第三站。
- 因為也參考了行動版版面，小螢幕上的呈現同樣良好。

## 補上動畫：UI skills MCP

- Inspo 不處理動畫，成品頁面是靜態的。
- 作者改用 UI skills MCP：可存取多位作者的設計 skill 庫，請 agent 依網站需求搜尋合適 skill。
- 此例 agent 載入了 Emil Kowalski 的動畫 skill 與 Meng To 的捲動動畫 skill，加入的動畫時序協調良好。
- 作者在其他多個網站上也測過 Inspo，多數情況效果不錯。

## 缺點

- **參考抓錯**：兩次測試中，即使 prompt 已明確說明網站類型，回傳的參考仍是不相關的類型。例如要求咖啡訂閱網站卻拿到健康與商業網站；改選 food & beverage 產業篩選後才拿到咖啡網站。
- **截圖被彈窗遮住**：部分截圖有開站彈窗蓋住設計，例如一張截圖正中央有隱私權彈窗，agent 看不到背後的設計，只能自行發揮那一塊——正是裝這個工具想避免的事。
- 對策：先請 agent 提出設計方向，及早發現偏離再重新下 prompt 修正。
