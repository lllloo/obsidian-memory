GStack 是 Garry Tan 開源的 agent workflow pack，把 planning、design、QA、ship 各階段包成可安裝到 agent host 的 skill / command 組，走「虛擬軟體團隊 operating system」取徑：用多 persona（CEO / Engineering / Design / DevEx）審查同一方案、再收斂成可執行 spec。可跨多個 agent host，包含 Claude Code。
