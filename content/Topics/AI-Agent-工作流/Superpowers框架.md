Superpowers 是以 TDD gate、systematic debugging、review loop 為核心的 agent 開發框架 / plugin，把品質門檻變成 workflow 硬閘——測試先寫、不通過不往下、code review 完才合併。可跨多個 agent host，Claude Code 透過官方 marketplace plugin 安裝。
