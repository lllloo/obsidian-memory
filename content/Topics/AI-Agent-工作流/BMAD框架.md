BMAD Method（Breakthrough Method for Agile AI Driven Development）是以 agile lifecycle 為骨架的多 agent 開發框架，定義 12+ 軟體角色（PM / Architect / Developer / UX 等）作為 persona，從 brainstorm、規劃、實作到部署各階段切片接力跑 user story；可跨多個 agent host。
