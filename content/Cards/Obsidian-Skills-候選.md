來自 YouTube 影片整理的候選清單，混錄 Claude Code skills 與相關 Obsidian 插件，分節區隔。

影片提到的 9 條 skill 中，前 4 條（defuddle / obsidian-cli / obsidian-bases / obsidian-markdown）已採用主集版本，詳見 [[Obsidian-Skills]]。本頁列其餘待評估項目。

## Skill 候選

1. **json-canvas（Axton 版）** — 比主集版本更優，節點排版自動計算正確
2. **mermaid（Axton 版）** — 高成功率的 Mermaid 圖表生成
3. **excalidraw（Axton 版）** — 視覺化頭腦風暴 skill，搭配同名 Obsidian 插件使用
4. **tutor** — 將文件 / PDF / GitHub 專案轉換成完整 Obsidian 知識庫，含雙鏈、MOC、測驗題
5. **scholar** — 學術科研導向，重度 token 消耗，適合深度論文學習

## 不推薦

- 主集的 `json-canvas`（排版有瑕疵，影片建議改用 Axton fork 版本）

## 推薦的 Obsidian 智能體插件

不是 Claude Code skill，是裝在 Obsidian 內、把 AI agent 接進編輯器的插件：

- **Claudian** — Obsidian 整合 Claude Code 的插件，透過 BRAT 安裝
- **obsidian-agent-client** — 支援多數主流智能體（Claude Code、Codex、Gemini CLI、OpenCode、千問 Code）
