## 用途

找前端設計靈感，避免生出千篇一律的 AI slop（紫色漸層、Inter 字體、通用 SaaS 模板）。

## 網站

[awwwards.com](https://www.awwwards.com/) — 業界最高水準的前端設計作品集，取代無聊的 AI 模板做為參考來源。

## 使用情境

- 用 Claude Code 做網站時，先到 Awwwards 挑一個高水準範例
- 可結合「網站解析（Site Teardown）」流程：HTML（`Ctrl+U`）+ 截圖 + 說明交給 Claude Code 學習
