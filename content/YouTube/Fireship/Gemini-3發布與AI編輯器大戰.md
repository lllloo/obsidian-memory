## Google 的大逆轉

- 2023 年 Bard 發布時直播中幻覺答錯，股價當天跌 9%
- 2025 年 Gemini 3 發布後股價漲 6% 創歷史新高
- Gemini 3 Pro 橫掃 LM Arena、Weird ML、Humanity's Last Exam、Math Arena 等主要排行榜
- **Amp（AI 開發工具）將 Claude 換成 Gemini 3 Pro**，稱其在所有指標上表現更好

## Anti-Gravity：Windsurf 的後續

- 2025 年 7 月，Windsurf 共同創辦人以非獨家授權加入 Google（$24 億交易）
- 現以 **Anti-Gravity** 品牌發布：VS Code fork，主打 agentic coding，由前 Windsurf 共同創辦人領導
- 亮點（或說笑點）：發布視頻中忘記把 Windsurf 的 coding agent「Cascade」改名

## AI 編輯器戰場一覽

| 工具 | 特色 |
|------|------|
| **Anti-Gravity** | Google 加持，前 Windsurf 團隊，agentic coding |
| **Chad** | Y Combinator 支持，整合娛樂（賭博/TikTok/Tinder）讓 agent 背景工作 |
| **IDX → Firebase Studio** | Google 的 web-based 編輯器，已改名為 Firebase Studio |
| **Jules** | Google 自主 coding agent |
| **Notepad++** | 作者個人最愛（諷刺） |

## 大局觀

- AI 模型大戰仍在持續，benchmark 霸主地位在 OpenAI 和 Google 之間輪換
- agentic coding 工具大量湧現，開發者從「寫程式」轉向「管理 agent」
