## 背景：HTTP 402 的誕生

- HTTP 402 狀態碼「Payment Required」自 1997 年就存在，一直是「保留未來使用」
- 問題：Stripe 等平台每筆交易收 $0.30 固定費，導致低單價 API（如每次 $0.01）根本無法盈利
- 傳統做法：OAuth 認證 → 訂閱/點數購買 → 消耗後補充，流程複雜

## X402 協議

- 由 **Coinbase** 開發的新協議，實現零手續費的即時微支付
- 支援穩定幣（如 USDC），也可用不到 1 分錢的金額
- 設計用於機器對機器（M2M）支付：AI Agent 可自動替 API 付款

## 運作流程

1. 買方向付費 API 發出 request
2. 伺服器回應 **HTTP 402**，代表需要付款
3. 買方看到連接錢包的頁面（或以程式自動處理）
4. 交易完成後，取得 response 內容

## 伺服器端實作（Node.js）

```javascript
import { x402 } from 'x402-sdk'

// 只需一行 middleware
app.use('/protected-route', x402({
  wallet: 'YOUR_WALLET_ADDRESS',
  route: '/protected-route',
  price: 0.01,           // 支付金額（USDC）
  timeout: 60,           // 允許完成交易的秒數
  network: 'base'        // 使用的去中心化網路
}))
```

## 客戶端程式化支付

```javascript
import { x402Fetch } from 'x402-sdk'

// AI Agent 可用此函式自動完成付款
const response = await x402Fetch('https://api.example.com/protected', {
  wallet: buyerWallet
})
```

## AI 經濟的意涵

- 開啟「AI 幫 AI 付錢」的可能性：Agent 自動購買其他 Agent 提供的付費 API
- 無需訂閱、無需帳號，純粹的按需付費
- MetaMask、Coinbase Wallet 等瀏覽器錢包可直接用於前端支付
