## 1. Mutable Instruments — 燃盡症候群

- 音樂合成器硬體公司，由 Emily Glay 獨立管理
- 手工撰寫 C++ 程式，能讓聲波做任何想像得到的事
- 問題：身為獨立業主，長期燃盡，她選擇轉換人生方向，專案就此淡出

## 2. Faker.js — 開發者反叛事件（2022）

- 每週數百萬次下載的 JavaScript 假資料生成庫
- 開發者 Marak Squires 在抗議「免費勞動無薪酬」後：刪除原始碼，以 `endgame` 文字取代，發佈 **6.6.6 版本**
- 導致數千個 JavaScript app 在更新依賴時崩潰
- 結局：他被從自己的專案踢出，由新開發者接手至今仍活躍

## 3. Parse — Facebook 收購後關閉

- 2011 年推出的 Backend-as-a-Service，為行動 app 提供資料庫與認證
- 2013 年以 **$85 million** 被 Facebook 收購
- 2016 年被 Facebook 關閉：「維護行動 app 基礎設施是浪費時間」
- 結局：開源了 Parse Server，開發者可自架繼續使用

## 4. Meteor — 生不逢時的全端 JS 框架

- 2013 年推出，全端 JavaScript（Rails 盛行時代）
- 技術特點：WebSocket + 有狀態伺服器，早期 demo 效果魔幻
- 問題：生產環境難維護、難水平擴展；React/Angular 出現後開發者選擇前後端分離
- 諷刺：後來的 Next.js 重新引入了許多 Meteor 的概念，但時機已過

## 5. OpenSolaris — Oracle 終結實驗

- 2005 年推出，基於 Sun Microsystems 的 Solaris Unix
- 技術上領先 Linux：ZFS 檔案系統、DTrace 可觀測性、容器（早於 Docker）
- 2010 年 Oracle 收購 Sun：開放開發停止，原始碼發布消失，實驗宣告結束
- 社群 fork 最後一版程式碼繼續維護
- 教訓：技術再好，所有權變更可以瞬間終結一切

## 補記：Firefox 的矛盾成功

- Netscape 面對 IE 靠 Windows 綑綁搶市場時，選擇將瀏覽器開源
- 程式碼品質一團糟，近乎完全重寫，期間 IE 快速佔領市場
- Firefox 終於發佈時，Netscape 已死；但 Firefox 重新啟動了瀏覽器競爭，奠定現代 web 基礎
- 開源可以打造更好的軟體，但打不過平台控制與發行通路
