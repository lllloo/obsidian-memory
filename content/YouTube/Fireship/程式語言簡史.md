## 計算機的起源

- 二進位：0 和 1 對應電的開與關，是電腦的語言基礎
- Alan Turing（1936）定義「可計算性」，後來用 Enigma 機破解納粹密碼
- 真空管與打孔卡用來表示 0 和 1
- 8 個 bit = 1 byte，可計數到 255

## 組合語言與第一代高階語言

- Ada Lovelace 時代的先驅後，是女性工程師推動了語言進化
- 組合語言：從寫機器碼的 `101100` 改為可讀的助記符
- Grace Hopper 發明 **compiler（編譯器）**：將可讀程式碼翻譯成機器碼
- 第一批高階語言：FORTRAN（科學）、COBOL（商業/政府）、Lisp（一切皆清單、garbage collection）

## 結構化與系統語言時代

- Dijkstra：「goto 是垃圾」→ 推動結構化程式設計
- Dennis Ritchie 發明 **C**：快速、可直接操作記憶體、讓人精準地射自己的腳
- Dennis + Ken Thompson 用 C 造出 **Unix**：小程式各司其職、透過 pipe 串接（`cd`, `ls`）
- **C++**：物件、類別、繼承，統治遊戲/瀏覽器/資料庫至今

## 90 年代三大哲學衝撞

- **Python**（Guido）：可讀性優先，縮排即語法
- **Java**（James Gosling）：Write once, run everywhere；JVM 把 Java 編譯成 bytecode，在虛擬機上執行
- **JavaScript**（Brendan Eich，10 天完成）：讓瀏覽器按鈕會動——現在跑遍 server、手機、資料庫、太空船

## 語言的精進時代（2000s）

- Swift 修正 Objective-C；Kotlin 修正 Java；TypeScript 修正 JavaScript；Go 修正 C；Rust 修正 C；Zig 修正 C——C 還是最好（誤）
- JavaScript 框架戰爭：jQuery → React / Angular / Vue / Svelte / 千千萬萬

## AI 時代的程式設計

- 2020 年後 AI 工具從自動補全進化到生成整個全端應用
- 「程式設計已死」的恐慌四起，但真正的工作從來不是「打字」——而是**思考**
- 打字的鍵盤一直在改變，但思考不會死
