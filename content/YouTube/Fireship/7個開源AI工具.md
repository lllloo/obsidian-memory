## 1. The Agency — AI agent 角色模板庫

- 免費開源，提供各種新創職能的 agent 模板：前端工程師、後端工程師、資安工程師、成長駭客、Twitter 互動等
- 可將多個 agent 組合在 Claude Code 中，從零到產品更有效率

## 2. Prompt Fu — prompt 單元測試框架（已被 OpenAI 收購）

- 測試不同 prompt 搭配不同模型，找出最佳組合
- 支援自動化 red team 攻擊，測試 app 是否有 prompt injection 漏洞

## 3. Mirrorish — 多智能體預測引擎

- 從網路抓取大量資料（突發新聞、金融趨勢等）
- 多個具獨立個性的 agent 互相討論資料，形成微型人工社交網路
- 可用於趨勢預測、策略分析

## 4. Impeccable — 前端設計優化 skill

- 開源，提供 17 個指令改善 AI 生成的 UI
- 常用指令：`distill`（簡化 UI）、`colorize`（套用品牌色）、`animate`、`delight`

## 5. Open Viking — AI agent 專用資料庫

- 不同於 vector database，以檔案系統組織 agent 的記憶、資源與技能
- 分層載入系統，大幅降低 token 消耗
- 自動壓縮內容與精煉長期記憶，越用越聰明

## 6. Heretic — 模型護欄移除工具

- 使用「obliteration」技術移除模型的安全限制
- 全自動，不需昂貴的 post-training；對象如 Google Gemma 等受限模型

## 7. Nano Chat — 從零訓練 LLM 的工具包

- 實作完整 LLM pipeline：tokenization、pre-training、fine-tuning、評估、Web UI
- 約 **$100 GPU 費用**即可訓練一個小型語言模型
