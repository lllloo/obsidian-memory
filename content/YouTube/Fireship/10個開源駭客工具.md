> 所有工具皆在 Kali Linux 預設內建。未獲授權使用滲透測試工具可能違反國際法律，只可在有明確授權的目標上使用。

## 1. Nmap — 網路掃描

- 掃描 IP 範圍，分析回應以找出開放的 port、作業系統
- `nmap <IP>` — 基礎掃描
- `nmap -A <IP>` — 進階掃描（OS 偵測、traceroute）

## 2. Wireshark — 封包分析

- 即時攔截並分析網路流量，支援數百種協定
- 建議使用 GUI 版本；適合偵測異常流量（如連到不明 IP 的封包）

## 3. Metasploit — 漏洞利用框架

- 強大的攻擊框架，可利用已知漏洞取得系統存取權
- 範例：利用 EternalBlue 漏洞對 Windows 7 機器建立 reverse shell
- 流程：搜尋漏洞 → 選擇 exploit → 設定 payload 與 LHOST → 執行

## 4. Aircrack-ng — Wi-Fi 破解

- `airmon-ng` 啟動監聽模式
- `airodump-ng` 掃描附近網路
- `aircrack-ng` 嘗試破解 WPA 金鑰

## 5. Hashcat — 密碼破解

- 支援多種策略：暴力破解所有組合、字典攻擊（如 `rockyou.txt` 含 1400 萬個常見密碼）
- 需指定 hash 演算法（MD5 可秒破，bcrypt 可能需數天）
- 現實中密碼以 SHA 或 bcrypt 加 salt 儲存，非明文

## 6. Skipfish — 網站漏洞掃描

- 遞迴爬取整個網站，掃描 XSS、SQL injection 等漏洞
- 產出 HTML 報告；支援帶憑證掃描已認證區域

## 7. John the Ripper / Hydra — 密碼破解（進階）

- 內建多種密碼攻擊模式（影片僅提及，未詳述）

## 8. Foremost — 數位鑑識資料還原

- 以「file carving」技術從磁碟映像重建已刪除檔案
- 不需要檔案系統；逐位元組掃描，識別檔案 header/footer pattern（如 JPEG）

## 9. SQLmap — SQL 注入與資料庫掃描

- 掃描網站/伺服器找出所有資料庫、表格結構
- 嘗試以 SQL injection 攻擊取得資料

## 10. hping3 — 封包洪水攻擊（DoS/DDoS）

- `hping3 --flood <IP>` — 以最快速度發送封包
- 單機為 DoS；與殭屍網路結合為 DDoS

## 社交工程工具 (SET)

- Social Engineering Toolkit：釣魚攻擊框架
- 支援 email、QR code、SMS、IoT 設備等攻擊向量
- 可複製網站作為釣魚頁面，攔截輸入的帳密
