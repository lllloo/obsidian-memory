## 概覽

- .NET 是免費開源的高效能軟體開發平台，涵蓋 Web、Mobile、企業軟體、遊戲等各種領域
- 主要語言：C#（物件導向）、F#（函數式）、Visual Basic（別問了）
- 歷史：2000 年代初為 Windows 專用框架 → 2016 重生為 .NET Core → 2020 統一為現代 .NET，每年發布新版，支援 Linux、macOS、雲端

## 核心架構：CLR（Common Language Runtime）

- 所有 .NET 語言都先編譯成 **CIL（Common Intermediate Language）**
- CLR 再將 CIL JIT（Just-in-Time）或 AOT（Ahead-of-Time）編譯為原生機器碼
- CLR 負責記憶體管理、垃圾回收、安全性——開發者不需手動處理

## 重要生態系

- **ASP.NET**：一般 Web 應用
- **Blazor**：WebAssembly 驅動的前端應用
- **Entity Framework Core**：簡單的資料庫存取 ORM
- **MAUI**：跨平台 Mobile 應用
- **Polly**：容錯（fault tolerance）函式庫
- **NuGet**：套件管理器，幾乎任何需求都找得到套件

## 第三方嵌入 .NET 的框架

- **Unity**：遊戲開發
- **QuantConnect**：演算法交易
- **AutoCAD**：工程設計

## 快速入門

```bash
# 安裝 .NET 後在 VS Code 啟用 C# DevKit
# Ctrl+P → New Project → Console App
dotnet run    # 編譯並執行
```

- C# 強型別，擁有優秀的 IntelliSense 支援
