## 核心論點

- Adobe、Salesforce、ServiceNow、Shopify 等 SaaS 巨頭市值在數週內蒸發 **1 兆美元**
- 原因：AI agent 可以替代 10 個人的工作，企業不再需要 10 個座位，需要的是 0 個

## 7 個支持論點

### 1. OpenAI Codex App（macOS）
- 定位為「agent 指揮中心」，首週超過 **100 萬次**下載
- 讓老闆可以自己建 app，只需要工程師來 debug AI 生成的一萬行程式碼

### 2. Codex 5.3 模型
- 比前版快 25%，可整合 skill（圖片生成、寫作、研究），覆蓋完整產品開發職責

### 3. Claude Opus 4.6
- Anthropic 切入法律分析、財務建模等企業場景，搶攻企業訂閱市場

### 4. Alibaba Qwen 3 Coder Next
- 開源權重的高效能 coding 模型，企業可自架防火牆後運行
- 消滅 SaaS 的另一優勢：**vendor lock-in**

### 5. ZAI GLM5
- 針對複雜系統工程與長期 agentic 任務，表現接近甚至超越頂尖閉源模型

### 6. MiniMax M2.5
- 頂級推理能力，計算成本極低、可攜帶、日益開放
- 讓 $200/月 AI 方案顯得多餘

### 7. GitHub Agent HQ（Microsoft）
- GitHub 從程式碼托管平台進化為 AI agent 完整協作平台
- Agent 可自動開 issue、建立 branch、測試通過後自動合併
- 整合專案管理、QA、DevOps 自動化

## 結論

> 當智慧變得充裕，軟體就不再按人頭收費。當座位消失，SaaS 的利潤率也跟著消失。
