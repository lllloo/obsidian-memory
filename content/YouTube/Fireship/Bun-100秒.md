## 是什麼

- JavaScript runtime 兼工具鏈，2021 年推出
- 目標：以單一 binary 取代 Node.js + npm + Webpack + Jest + Babel 整個工具鏈
- 技術選型：C++ 換成 **Zig**，Chrome V8 換成 **JavaScriptCore**（Safari 使用的引擎）
- 現已為 Claude Code、Cloudflare serverless functions 等提供支援

## 核心功能

| 功能 | 說明 |
|------|------|
| Runtime | 相容 Node.js 生態系 |
| Bundler | 原生支援 TypeScript、JSX，零設定 |
| Package manager | `bun install` — 比 npm 快 **25 倍** |
| Test runner | 內建，速度極快 |
| SQLite driver | 內建 `bun:sqlite` |
| Redis driver | 內建 Redis 支援 |
| S3 driver | 內建 S3 bucket 操作 |

## 快速上手

```bash
# 安裝
curl -fsSL https://bun.sh/install | bash

# 新建專案
bun init

# 執行（支援 TypeScript，不需額外設定）
bun run index.ts

# 監聽變更自動重啟
bun --watch run index.ts

# 安裝依賴
bun install

# 執行 npm executables
bunx <package>

# 跑測試
bun test
```

## HTTP Server 範例

```typescript
// 使用內建 Bun HTTP module，不需 Express
Bun.serve({
  port: 3000,
  fetch(req) {
    return new Response("Hello World");
  },
});
```

## SQLite 範例

```typescript
import { Database } from "bun:sqlite";
const db = new Database("mydb.sqlite");
```
