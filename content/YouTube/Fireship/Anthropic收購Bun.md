## 收購事件

- Anthropic（Claude 背後的 AI 公司）收購 **Bun**——JavaScript/TypeScript 全合一工具包
- Bun 於 2022 年由 Jarred Sumner 發起，以 Zig 重寫 esbuild 的 JSX/TypeScript 轉譯器

## Bun 的起源與成長

- Jarred 曾是 Stripe Teal Fellow 高中輟學生，搬到 Oakland 花一年打造 Bun
- 核心定位：最快的 all-in-one **bundler、transpiler、runtime、test runner、package manager**
- 獲得 Kleiner Perkins $700 萬種子輪
- 2023 年發布 1.0；2024 年支援 Windows
- 目前：每月超過 700 萬次下載、83,000+ GitHub Stars
- 內建 PostgreSQL、MySQL、Redis 客戶端

## 為什麼 Anthropic 要買 Bun

- Bun 應用可編譯為單一可執行檔，非常適合建立 **CLI 工具**——Claude Code 就是用 Bun 打造的
- AI Agent 需要快速且可預測的執行環境，Bun 正好符合
- 未來 AI 寫的程式碼也需要高效的執行平台

## 收購後的承諾與疑慮

**Bun 團隊的承諾：**
- 維持開源（MIT 授權）
- 持續公開開發
- 同一團隊繼續工作

**疑慮：**
- Anthropic 在開源方面紀錄不佳（Claude Code 本身就不開源）
- 許多受歡迎的開發工具在被收購後遭到廢棄
