## 企業 AI 碎片化問題

企業 AI 採用快於架構規劃，導致：
- 各部門使用不同供應商和模型
- 重複訂閱、成本難以追蹤
- 沒有集中治理，合規團隊只能被動應對
- 接觸法規資料（財務、醫療、法律）的 AI 變成風險面

解法不是更多模型，而是一個統一的控制層，整合模型、企業資料和政策。

## Demo：文件審核 Agent

以費用報告審核為例，使用 Airia 平台建立：

1. 開啟 Airia builder，建立新 Agent
2. 用自然語言說明需求：審核上傳文件、對照公司政策、輸出每個項目的批准 / 拒絕判斷
3. 上傳公司費用政策文件，確保 Agent 依照既有標準審核
4. 透過 chat interface 測試：上傳測試費用報告 → Agent 幾秒內回傳逐項分析

**微調流程：**
- 若某項被標記太嚴格 → 回到 builder 微調指示 → 再次測試
- 無需寫程式，拖放介面 + 自然語言即可調整

## Agent 能力

- 同時處理多份文件
- 從政策文件解讀規則
- 可連接其他工具：
  - 自動記錄審核結果
  - 被標記時通知主管
  - 整合至更大型的審核工作流程

## 企業 AI 成熟度的演進

| 階段 | 描述 |
|------|------|
| 單一助理 | 回應單一 prompt |
| 連接 Agent | 在安全邊界內協作 |
| 治理嵌入 | 合規與可稽核性內建 |
| 可預測支出 | 路由智能 + 生命週期管理 |

下一階段將是 Agent 網絡跨系統協作：財務對帳、法律合約審查、HR 政策篩選、行銷分析，全部連接核心企業基礎設施。
