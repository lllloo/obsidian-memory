## 核心問題

多數 B2B SaaS 團隊面對的不是「數據問題」，而是「答案與清晰度問題」：
- 數據確實存在（GA4、CRM、Stripe、廣告平台），但分散在五個不同工具
- 有人問「為什麼本月簽約數下滑？」時，需要有人手動拉數字、跨工具比較、整理成報告
- 瓶頸不是資料收集，而是從散亂指標到可行洞察的速度

## Databox 是什麼

AI 驅動的分析平台，核心定位是「資料 → 解釋 → 行動」，而非只是更好看的 dashboard：

- 支援 130+ 原生整合（GA4、HubSpot、Salesforce、Stripe、試算表、SQL、Zapier、Make）
- 可合併多來源資料集、定義自訂指標，確保全團隊用同一套定義

## 四步驟工作流

1. **連接來源**：接上現有工具（GA4、廣告平台、CRM、Stripe、SQL）
2. **準備數據**：用 Dataset / Merge Dataset 整合、過濾、計算自訂欄位，讓數據符合分析需求
3. **視覺化**：從模板開始拖拉指標到 dashboard，或讓 Genie AI 從 prompt 自動生成視覺化
4. **提問**：用 Genie（AI 分析師）直接問業務問題，不需手動翻 dashboard

## Genie — AI 分析師

- 用自然語言提問：「為什麼這個指標上週下滑？」「哪個渠道真的在推動 pipeline？」
- 比較時間段、生成績效摘要、追蹤目標進度、預測達標率
- 可追問深入細節，或分享含圖表的完整對話連結給團隊
- 可從 prompt 直接生成 dashboard 和視覺化，不需全手動建立

## Databox MCP 整合

連接 Databox 到 ChatGPT、Claude、Cursor 等 MCP 客戶端：
- 在 AI 工具內直接查詢業務數據
- 建立對指標有反應的自動化流程
- 不需開 dashboard 就能生成績效摘要
- 讓 AI 工作流取得可信、標準化的業務數據脈絡

## 自動化報告與警報

- 排程快照、Slack/Email 推送報告
- 設定目標追蹤與績效警報
- 建立可重複的週期性作業節奏（週報、月報、領導層摘要）

## 誠實評估

**適合的情境：** 資料已跨多工具分散，需要更快速從指標到解釋到行動，且想將 dashboard、AI 分析、報告、自動化整合在一個系統。

**不適合的情境：** 資料本身混亂、KPI 定義不一致、團隊不清楚要測量什麼——工具本身無法修復這些問題。
