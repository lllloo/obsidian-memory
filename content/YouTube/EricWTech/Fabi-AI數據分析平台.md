## Fabi.ai 定位

AI 分析師坐在你的資料上方，讓團隊用自然語言、SQL、Python 或零程式碼取得數據洞察。解決的問題是：打開 dashboard 看著圖表卻不知道下一個問題要問什麼。

## 支援的資料來源

Google Sheets、Postgres、BigQuery、Snowflake、Redshift、Stripe、HubSpot、Google Analytics、Slack、Databricks 等。連接後自動理解資料結構，不需手動定義 schema。

## 核心功能

### AI 問答查詢
輸入英文問題 → AI 自動撰寫 SQL/Python → 執行分析 → 生成圖表或表格。可接續追問（「依地區分析」、「改為月趨勢圖」），不需重新開始。

### Smartbook
儲存 AI 產出的表格、圖表、SQL/Python、洞察的互動工作區：
- 類似進化版的 Jupyter notebook，但為協作而生
- 行銷、產品、數據團隊可在同一環境工作
- **反應式（reactive）**：資料更新時分析自動更新，不需重建 dashboard

### Dashboard 共享與 AI Analyst Agent
從 smartbook 一鍵生成 dashboard → 分享給團隊後，**成員可對 dashboard 直接提問**，AI Analyst Agent 即時回答，無需技術背景。實現自助式分析，同時保留資料治理控制。

### 自動化工作流
排程分析（每日/週/月）→ 直接推送到 Slack、email、試算表。觸發條件：收入下降、留存率變化、指標超過閾值——AI 通知時附帶解釋，不只是原始數字。

### 技術靈活性
- 無程式碼：純自然語言
- SQL/Python：直接撰寫
- 混合模式：兩者結合
- Python notebooks 支援協作、版本控制、reactive cells
- **支援 MCP**：可整合到其他 LLM 或 chat 介面，讓 AI agent 操作真實資料

## 內建模板

Google Sheets dashboard、情感分析、留存分析、時間序列、聚類分析等。連接資料後 AI 自動適配到你的業務情境。

## 適用團隊

- 產品團隊：用戶留存、cohort 分析、行為追蹤
- 行銷團隊：廣告效果、歸因分析
- 營收團隊：成長、churn、LTV 監控
- 數據團隊：ad-hoc 分析，減少重複報表請求

## 合規

SOC 2 compliant、GDPR ready、CCPA ready。

## vs 傳統 BI 工具

傳統 BI：先建報表再問問題。Fabi：先問問題再把答案變成 dashboard 和工作流。定位是補充而非取代現有 BI 工具。
