## 影片描述

完整示範如何使用 Claude Cowork 自動化日常工作，涵蓋與 Claude Code / Claude Chat 的差異、專案設定、工作流程建立、Skill 轉換，以及 Plugins、排程任務和記憶功能的探索。

## 重點摘要

### Claude Cowork 是什麼

- Anthropic 推出的工作流程自動化平台，有別於 Claude Chat（對話介面）和 Claude Code（CLI 開發工具）
- 核心賣點：可以把工作流程封裝成可重複使用的 Skill，並支援排程執行
- 適合用於結構化、重複性的任務自動化

### Claude Cowork vs Claude Code vs Claude Chat

| 工具 | 主要用途 |
|------|---------|
| Claude Chat | 即時對話，一次性問答 |
| Claude Code | CLI 開發工具，修改程式碼與執行指令 |
| Claude Cowork | 工作流程自動化，可排程、可重用 Skill |

### 實際示範：收據轉 CSV

- 上傳收據圖片，自動提取資料並轉換為 CSV 格式
- 展示如何將這個流程儲存為 Skill，供日後重複呼叫

### Skill 的概念

- Skill 是可封裝、可複用的自動化工作流程
- 可以在不同 project 中引用，提升效率
- 類似 Claude Code 的 `/skills` 概念，但整合在 Cowork 平台中

### 其他功能

- **Plugins**：擴充 Cowork 的整合能力（連接外部服務）
- **排程任務（Scheduled Tasks）**：設定定時自動執行工作流程
- **記憶（Memories）**：跨 session 記住用戶偏好或背景資訊
