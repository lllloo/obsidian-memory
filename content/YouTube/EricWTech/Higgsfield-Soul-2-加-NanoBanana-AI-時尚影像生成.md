## Soul 2.0 是什麼

Higgsfield 的時尚影像生成模型，定位是「品味導向」而非只是「高畫質」：
- 理解 Y2K studio vibes、lo-fi streetwear 等次文化參考，轉化為構圖、打光、質感
- 目標：圖像看起來像廣告拍攝出來的，而非 prompt 隨機產出的
- 介面：prompt box + Soul ID + Hacks + Mood Board 整合在同一個地方

## 步驟一：撰寫 Prompt

把 prompt 當成創意簡報，而非描述。要給的不是「cool fashion portrait」，而是：

```
cinematic portrait of a male model in early 2000s streetwear,
shot at night under neon signs, subtle film grain, editorial framing
```

Soul 2.0 針對文化與時尚線索訓練，越具體越能發揮。

## 步驟二：選擇 Preset（風格錨點）

可用 Preset 預先鎖定大方向，讓 prompt 只需處理細節：

| Preset | 適用情境 |
|--------|---------|
| Y2K Studio | 千禧年街頭、強光直打 |
| Warm Ambient | 暖色調室內 |
| Subtle Flash | 閃光燈感、紀實風 |
| Mystique City | 城市夜晚、神秘感 |

## 步驟三：生成後微調

生成後評估是否有「意圖感」：打光、服裝質感、背景深度、整體構圖。
若方向接近但不到位，微調 prompt：

```
原本太乾淨現代 → 加入 "harsh direct flash, candid energy, slightly off-center framing"
```

## 步驟四：Reference Mode（建立系列視覺）

用既有生成圖或外部參考圖作為基底，生成保持相同美學 DNA 的變體：
- 構圖與風格基調維持一致
- 角色可能改變姿勢或表情
- 效果：像同一次拍攝出來的多張照片，而非多個不相關的 AI 輸出

## 步驟五：Soul + Nano Banana 工作流

**兩個模型分工：**

1. **Soul 2.0** → 建立基底（構圖、打光、整體氛圍正確）
2. **Nano Banana 2**（Google 最新模型）→ 精修：質感細節、加入圖形元素、文字疊加，推向可發布品質
3. 再回到 Soul → 基於同一方向生成更多變體

Nano Banana 在「起始圖已夠好」的情況下表現最佳，因此順序很重要。

## 步驟六：Soul ID（角色一致性）

跨場景保持同一個人物：

1. 上傳生成圖或真實照片 → 建立 Soul ID 檔案
2. 後續生成時選擇該 Soul ID
3. 換完全不同的 scene/style（如從霓虹街頭換成奢華棚拍），臉部與核心身份維持不變

```
prompt: high fashion studio portrait, soft diffuse lighting, luxury tailoring, minimal background
+ Soul ID 選擇原本的角色 + 換 preset 到更乾淨的風格
```

## 步驟七：進階風格控制

**Soul Hacks（色彩轉移）：**
- 上傳一張有特定色調的參考圖（例如青橙電影感）
- 後續生成會套用該特定色彩平衡
- 適合：品牌色管理、保持社群 feed 色調一致

**Soul Mood Board（多圖定義方向）：**
- 上傳多張參考圖，定義整體創意方向
- 不需要在 prompt 裡逐一描述每個細節
- 操作：General 區塊 → My Mood Board → Build Your Mood Board → 上傳圖片

## 完整工作流總結

```
Soul 2.0（基底生成）
  → Nano Banana（精修）
  → 回到 Soul（同方向更多變體）
```

搭配：Soul ID（角色一致）+ Hacks（色彩一致）+ Mood Board（風格方向）

## 適用場景

- **社群內容**：定義角色 + preset → 批量生成一致系列
- **品牌活動**：mood board 定向 + Hacks 對色 + Soul ID 固定角色
- **個人品牌 / 虛擬 KOL**：建立可跨場景複用的人物形象

**誠實評估：** 無法取代完整攝影棚，但對需要速度、一致性、控制力的創作者是可長期使用的工具。Higgsfield.ai 提供免費額度可測試。
