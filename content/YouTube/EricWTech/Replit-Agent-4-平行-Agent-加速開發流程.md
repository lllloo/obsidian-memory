## 重點摘要

Replit Agent 4 的核心定位是「創意優先」的建構 agent，4 大主軸：

1. **Design Freely（自由設計）**：無限畫布視覺探索，可產生多個 UI 方向比較後套用。內建視覺編輯器（canvas + live preview），可直接點擊介面修改文字、間距、顏色、版面，簡單編輯直接更新程式碼，複雜變更交給 agent 處理。

2. **Move Faster（更快推進）**：Path system 將大任務拆成離散子任務，可視化追蹤狀態（計劃中/執行中/待審查/完成）。Pro 方案支援平行執行，多個 thread 同時處理前後端與設計。

3. **Ship Anything（任何產品都能發）**：同一個專案可建構 web app、mobile app、投影片、數據應用、動畫等。支援連接 Notion、Slack、BigQuery、Linear 等外部服務。General Agent 可從自然語言出發，不需預先設定技術棧。

4. **Build Together（協作建構）**：多人可在同專案各自開 thread 互不干擾。Core 方案任務依序執行；Pro 方案平行執行，更接近真實團隊作業方式。

**重要轉變：**
- 不再需要預選技術棧（舊版 stack selector 將消失）
- 支援現有專案，非僅限新建
- 支援 mobile app 預覽（透過 Expo Go）
- Agent 4 vs Agent 3：Agent 3 強調自主性，Agent 4 強調創意控制與可見度
