## 問題：多工具造成協調開銷

現有 AI 創作流程通常是：圖片一個工具、影片另一個、Avatar 又一個、語音又另外一個、回饋在 Slack、素材在 Drive。這不是製作，是協調開銷。

Topview 4.0 是一個協作式 AI 影片創作 board，將所有步驟整合在同一個工作空間。

## 四步驟系統

### Step 1：結構化發想（Text-to-Image）

- 平台整合多個模型：Kling、Seance、Banana Pro 等，不需外部 API
- 一次生成 4 個變體
- 原則：**批量生成，積極篩選** — 立即星標最強的，忽略弱概念
- 每個素材顯示使用的 prompt 和模型，方便後續迭代

### Step 2：圖片直接轉影片

- 在 board 內直接把最強圖片轉為影片（不需下載再上傳）
- 加上動態 prompt，選模型，生成
- 等第一個渲染時，同步生成第二個變體 — 永不等待單一輸出

### Step 3：加入 AI Avatar 與語音

- 在同一個 board 內生成 AI Avatar
- 貼入腳本，選擇語音（支援多語言和口音）
- 原則：**保持聲音 profile 一致**，跨變體的一致性直接提升感知製作品質

此時已有：B-roll（背景影片）+ A-roll（Avatar）+ 語音，全部在一個 board 上。

### Step 4：協作迭代

- 直接在素材上留評論（而非在 Slack）
- 重新生成時錨定到原始素材，不是大量編輯後的版本 — 防止跨平台疊加的細微誤差
- 可直接分享 board 給客戶，他們對特定場景留言，沒有下載重傳的混亂

## 複製已驗證的廣告結構

看到一個有 1000 萬觀看次數的廣告，不需要重新雇人拍攝，在 board 內：
1. 拆解結構：Hook → 問題 → 解決方案 → CTA
2. 重建開場視覺，匹配節奏
3. 插入自己的產品，換上自己的 Avatar
4. 同一結構，換上自己的品牌

每個驗證概念建立一個 board，多個概念可並排比較、迭代。

## 核心優勢

- AI 生成快，人工組織慢 — Topview 減少這個摩擦
- 整合多個模型的成本，比分別訂閱各家 API 更集中
- 優勢不在於單一 prompt 的輸出品質，而在於**系統設計**
