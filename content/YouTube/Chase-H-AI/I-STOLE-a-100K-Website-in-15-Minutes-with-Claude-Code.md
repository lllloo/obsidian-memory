示範如何用 Claude Code 在 15 分鐘內「複製」一個 $100K 等級的網站設計，並轉化為自己的創作。

## 五步驟流程

1. **找靈感**：到 [Awwwards](https://www.awwwards.com/) 等平台尋找想複製的網站
2. **Site Teardown**：提供 HTML、URL、截圖，使用 site teardown skill 讓 Claude Code 分析 CSS 與 JavaScript
3. **Asset Creation**：用 AI 工具（Nano Banana Pro + VO3.1）建立所需素材，建議使用綠幕方便後處理；把圖片做成影片再逐幀擷取
4. **Build Phase**：將素材交給 Claude Code，根據分析結果建構網站
5. **Iteration**：對比原版與自製版本，截圖回饋給 Claude Code 反覆調整，最終改成自己的版本

## 重點摘要

- 目的不是盜版，而是透過「臨摹」學習前端設計知識（GSAP、scroll trigger、Lenis 等）
- Claude Code 抓 JS/CSS 時實際呼叫較小模型執行 web fetch，大型檔案可能抓不完整，需要特製 skill
- 月亮陰影效果：54 張靜態圖 vs. 自製版從影片逐幀擷取（4 秒影片 ≈ 50-70 幀）
- 最終產出是「90% 的解決方案」，不可能 1:1 複製設計工作室的成品
