**影片描述**：Chase H 作為一人團隊，在 30 天內用 Claude Code 內容系統產出 90 支影片（30 部長片 + 60 部短片），衝破 1,000 萬觀看，無編輯、無助理。本影片完整拆解背後的七個 Claude Code skills 和四階段流程。

**重點摘要：**
- 成績的關鍵不在於幾支爆紅影片，而是 90 支影片無一超過 40 萬觀看——是可重複的系統性小勝，而非靠運氣，任何人都能複製。
- 內容製作分四階段：Research（研究）→ Ideation（構思）→ Scripting（腳本）→ Distribution（發佈），每個階段有專屬 Claude Code skill 支撐。
- Research 的核心是找到「知識源頭」：AI 領域的源頭是 Twitter 和 GitHub（再流向 YouTube），不同 niche 需要找對應的源頭才能比別人早一步。
- Twitter 研究引擎：Chase 自建的 Twitter 爬取 web app，每 30-45 分鐘抓取 40-90 則推文，依 velocity、authority、timing、opportunity、replyability 評分，透過 Softmax 隨機化後推送至 Telegram，並支援直接回覆。
- GitHub 趨勢腳本：每日早晨推送過去 7 天 AI 類 Top 10 trending repos 至 Obsidian vault，確保不錯過新興工具。
- YouTube Pipeline Skill：透過 NotebookLM CLI 工具橋接 Claude Code 與 NotebookLM，分析工作外包給 Google Gemini，不消耗 Claude token；是最強大的七個 skills 之一。
- Ideation Skill：分析競爭格局、找出市場缺口、提供影片構想（含角度、desire mapping、排名）；AI 輔助分析，人類做最終決策。
- Scripting 三個 skills：Hook Skill（產生 5 種 hook 變體）、Outline Skill（大綱、章節、視覺輔助）、YouTube Title Skill（Tier 1 穩健 / Tier 2 計算性冒險）；所有輸出存入 Obsidian vault 交叉參照。
- Distribution 兩個 skills：Content Cascade Skill（YouTube → Blog + Twitter 串 + LinkedIn）、Short Form Skill（長片濃縮為 30/60/90 秒短片腳本），一部影片衍生六個平台內容。
- 縮圖是唯一不讓 AI 做的事：AI 在純視覺創意上仍不夠好，Chase 堅持手工製作。
