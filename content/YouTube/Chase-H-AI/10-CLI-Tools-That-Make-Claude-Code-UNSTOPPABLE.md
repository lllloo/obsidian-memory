Chase H 介紹他最喜歡的 10 個 CLI 工具，涵蓋 YouTube 研究、應用部署到 Google Suite 控制。

## 10 個 CLI 工具清單

1. **CLI Anything** — 為任何開源專案自動生成 CLI 工具（來自 LightRAG/RAG Anything 團隊）
2. **NotebookLM-py** — 讓 Claude Code 控制 Google NotebookLM，可分析 YouTube 影片、生成播客/投影片等，完全不消耗自己的 token
3. **Stripe CLI** — 簡化 Stripe 產品建立與管理流程，避免繁雜的 Web UI 操作
4. **FFmpeg** — 影音處理工具，可分割影片幀、製作循環動畫等
5. **GitHub CLI (gh)** — git/GitHub 操作從終端完成，Claude Code 已內建良好支援
6. **Vercel CLI** — 部署管理工具，搭配 GitHub 可建立 CI/CD pipeline
7. **Supabase CLI** — 資料庫與身份驗證一站管理，開源且支援本地執行
8. **Playwright CLI** — 瀏覽器自動化，比同功能 MCP server 快且省 90,000 tokens
9. **LLMFit** — 分析系統硬體，推薦最適合的本地開源模型
10. **GWS (Google Workspace CLI)** — 控制 Gmail、Docs、Sheets 等整個 Google Workspace

## 重點觀察

- CLI 工具勝過 MCP 的核心優勢：兩者同住終端，無額外 overhead，token 消耗更少
- 大多數 CLI 工具需搭配對應的 **Skill** 才能讓 Claude Code 正確使用
- 趨勢：業界正從 MCP 轉向 CLI 工具生態
