Daniel Terhorst-North 說明 OKR（Objectives and Key Results）被誤用的三大環節，以及如何回歸 Andy Grove 的原始設計意圖。

## OKR 的起源與設計目的

1970 年代，Intel CEO Andy Grove 受 Peter Drucker 的 MBO（管理目標法）啟發，但發現 MBO 的問題：**獎勵中庸**——目標設太高失敗就受罰，於是大家都低球，年年達成低目標、領獎金。

Grove 的修正：
- Objective 應是**激勵人心的抱負**（aspirational），不是操作目標
- Key Results 應讓人有點緊張（butterflies，不是 nausea）
- 重點**不是達成目標，而是看能走多遠**

## 三大失敗環節

### 1. 定義錯誤

常見錯誤：
- Objective 寫的是「做什麼」而非「達到什麼」（activity vs. outcome）
- 例：「降低客戶流失率」是 operational，不是 aspirational
- 正確方向：「主宰這個市場領域」、「大幅縮短 time to value」

Key Results 的正確定義（Josh Seiden《Who Does What by How Much》）：
- **Who**（目標受眾）+ **Does What**（行為改變）+ **By How Much**（可量測）
- 不是行為改變的指標 = vanity metric

### 2. 追蹤方式錯誤

週會只討論「做了什麼」，不看「離目標多近」。

正確問法：**「快到了嗎？」（Are we nearly there yet?）**

Christina Wodtke《Radical Focus》的週會四象限框架：
1. **信心程度**：多有把握達到這個 key result？
2. **健康指標**：不能犧牲的底線（人員、財務、組織）
3. **外部動態**：組織內外的重要資訊
4. **本週優先事項**：根據前三項決定

### 3. 季末檢討錯誤

最常見也最嚴重的錯誤：**把實際達成數字跟目標比較**。

這樣做 = 回到 MBO 思維 = 懲罰野心。

正確做法：**完全忽略原訂目標數字**，只看「走了多遠」。

例子：
- 錯誤：「目標 10，只達 8，沒達標。」
- 正確：「居然達到 8，以前從沒超過 5，你們怎麼做到的？」

## Goodhart's Law 的延伸

> 當一個指標變成目標，它就不再是有效的指標。

OKR 版本：**當抱負變成目標，你需要夢更大。**

一旦 key result 跟績效獎金掛鉤，等於重新引入 loss aversion（損失趨避），破壞所有激勵效果。參考 Daniel Pink《Drive》：真正的動機來自自主（Autonomy）、精通（Mastery）、目的（Purpose），外在激勵有毒。

## 正確使用 OKR 的要點

- Objective 要令人興奮
- Key Results 關注目標受眾的**行為改變**
- 週會聚焦 OKR 進度，但也追蹤健康指標
- 季末**忘掉目標數字**，只問：走了多遠，下次怎麼走更遠
