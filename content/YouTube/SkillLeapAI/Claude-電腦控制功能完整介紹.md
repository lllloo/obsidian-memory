## Claude Computer Use 是什麼

Claude Computer Use 讓 Claude 能像人一樣操作 Mac 電腦：看畫面、移動游標、點擊按鈕、輸入文字、開啟應用程式、切換視窗，並逐步完成任務。

與一般對話式 Claude 不同，不需要來回互動——給一個任務，讓它自動執行。

## 三種使用模式

- **Claude Co-Work**：給任務讓它執行，但你不會即時看到操作過程（背景執行）
- **Claude Computer Use**：即時觀看 Claude 操作電腦畫面（可視化執行）
- **Claude Code**：透過寫程式完成任務，Computer Use 也可與此模式搭配

## 安裝與設定步驟

1. 下載 Claude Desktop App（mac）：claude.ai/downloads
2. 開啟 App 後可見 Claude Co-Work、Claude Code、Dispatch 三個模式
3. 在設定中開啟：
   - **Keep computer awake**：防止電腦休眠干擾任務
   - **Dispatch**：開啟手機遠端控制功能
4. 使用 Opus 4.6 模型執行 Computer Use 任務

## 五個實際展示案例

### 案例一：整理檔案（較慢）
給予任務：在特定資料夾中整理檔案。
- 執行時間比手動慢，但完全自動
- 主要優點：可在背景執行，不需在旁等待

### 案例二：開啟 Dropbox 深層檔案
- 給定精確檔名，要求找到並操作
- Claude 自動導航進入 Dropbox 深層目錄
- 可自行選取文字、複製內容

### 案例三：分析網站並重建
- 任務：搜尋自己的網站、分析後用 Claude Code 重建
- 結果：寫出超過 2,000 行程式碼，還原設計並加入動態效果
- 即使在 Co-Work 分頁執行也能觸發 Claude Code

### 案例四：搭配 Dispatch 用手機控制
- 手機配對桌機後，可從手機傳送任務
- 示範任務：找最新螢幕錄影 → 重新命名 → 移到 Dropbox → 傳回連結
- 執行結果：成功完成所有步驟，連結存在文字編輯器

### 案例五：行程整合（進行中功能）
- 理想情境：手機當對講機，傳訊息給桌機上的 Claude
- 可設定排程自動執行
- Claude 完成後透過手機通知

## 目前的限制與評估

- **速度慢**：第一次執行任務明顯比手動慢
- **仍處早期**：部分互動不穩定，某些操作需要多次嘗試
- **隱私風險**：Claude 可看到整個畫面，需謹慎使用
- 作者評估：適合早期測試者，尚未達到日常工作使用水準

## 最佳適用情境

- 電腦執行長時間任務時人不在旁
- 搭配手機 Dispatch 遠端指派任務
- 需要跨應用程式協調的複合任務
- 測試與研究 AI 能力邊界

## 與 Claude Co-Work 的關係

作者目前主要使用 Claude Co-Work（不含即時螢幕視覺），認為 Computer Use 是下一步的重大突破，但 Co-Work 目前已是最常用的 AI 工具，超越 ChatGPT 等競品。
