## 什麼是 Claude Co-work

- Claude Desktop App（Mac/Windows）的三個功能分頁之一：Claude Chat、Claude Co-work、Claude Code
- Co-work 是 agentic 平台，可存取電腦上的資料夾、建立與編輯多份文件、長時間執行任務
- 需付費方案（$20/月起，但作者升級到 $200/月 Max 方案以獲得更多用量）

## 七個實際使用案例

### 案例一：整理電腦截圖

- 給予存取特定資料夾的權限，Co-work 自動掃描 2900 張截圖
- 自動建立分類資料夾、將截圖移入對應資料夾、依內容重新命名檔案
- 無需手動操作，完全自動化

### 案例二：完整行銷活動企劃

- 給予資料夾（含品牌指南、競品分析、產品照片、Logo）的存取權
- 一個 prompt 後，Co-work 在約 10 分鐘內建立：
  - Meta 廣告、Google 廣告（含標題與描述）
  - 完整部落格文章（含標題，可直接複製貼上）
  - 電子報草稿（含版面規劃）
  - HTML 登陸頁面
  - A/B 測試文件
  - 30 天行銷策略（逐日規劃）
  - 完整 PowerPoint 簡報
- 後續追加 prompt 可生成更多部落格文章

### 案例三：會議準備

- Prompt 範本：「我下週與 [公司名] 開會，請先問我必要問題，再提供研究報告」
- 搭配 Connectors：連接 Google Drive（SOP、筆記）、行事曆（直接讀取會議對象）
- 輸出：公司概覽、近期動態、商機、關鍵人物等單頁摘要

### 案例四：出差行程規劃

- 一個 prompt 生成：每日行程、飯店選項（含地圖與預訂連結）、打包清單（含目的地天氣）、費用追蹤試算表、行前注意事項
- 建議為每個任務建立新資料夾，讓輸出自動整理

### 案例五：優化行事曆

- 連接 Google Calendar → 讀取當週行程 → 找出 2 小時以上空檔
- 提出行事曆優化建議 → 使用者確認後 → 直接在 Google Calendar 新增 ICS 行事曆項目（一鍵加入）

### 案例六：生成品牌簡報

- 搭配 Claude Projects（存放品牌指南、版面規範、圖表設計標準）
- Co-work 參照 Projects 中的文件，生成符合品牌規範的 PDF 與 PowerPoint 簡報

### 案例七：銷售外發郵件

- 安裝官方 Sales Plugin，提供目標客戶清單、外發範例信件與服務說明
- 輸出：26 頁文件，含優先排序的客戶名單、針對每位客戶個人化的開發信、後續追蹤信、LinkedIn 訊息

## Skills 與 Plugins

- **Skills**：Markdown 格式自訂指令，可安裝至專案或帳戶層級；社群市集有現成 skills 可複製貼上
- **Plugins**：Anthropic 官方提供的現成工作流（如客服、財務、法務、行銷、銷售類），也可從 GitHub 市集取得或自製

## 費用方案

- $20/月（月付）：含 Co-work 與 Claude Code，但用量有限制
- $100-$200/月（Max 方案）：依用量計費，用量上限顯著提高
- 企業方案（Team/Enterprise）：同樣可存取 Co-work 與 Claude Code
