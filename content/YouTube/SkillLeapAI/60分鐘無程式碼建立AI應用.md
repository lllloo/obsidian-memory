## 使用平台：Emergent

- Emergent 是一個 agentic AI 程式碼生成平台，能建立生產就緒的真實 app，而非單純原型
- 無需 API 金鑰，Emergent 提供通用金鑰，可直接串接 OpenAI、Claude、Gemini 等模型
- 主要特色：自動截圖並回饋給自身、內建測試 agent 自動測試功能，無需手動回報錯誤

## 建立流程

1. 在 Emergent 輸入文字 prompt（可以用 ChatGPT 先做腦力激盪後再貼入）
2. 設定選項：上傳截圖作為 UI 參考、選擇 agent 類型（穩定型或進階型）、選擇 AI 模型（最大支援 100 萬 token 上下文視窗）
3. 模型回問需要哪種 AI 整合、API 金鑰、是否需要身分驗證
4. Agent 自動執行建置，完成後提供側邊即時預覽

## 實際建立的 App：AI Startup Mentor

一個幫助使用者從 0 到 1 建立商業的 AI 驅動平台，包含：
- **身分驗證**：使用者可建立帳號，資料儲存至資料庫
- **信用點數系統**：新用戶獲得 10 點 AI 積分
- **創業發想聊天機器人**：對話式引導提出商業想法
- **驗證聊天機器人**：驗證商業可行性
- **命名聊天機器人**：提供商業名稱建議
- **Logo 生成器**：使用 Nano Banana（Google Gemini 圖像模型）生成 Logo，每次輸出兩個版本
- **商業計畫生成器**：由 Claude 驅動
- **待辦清單**：列出創業所需步驟（含 SBA 官網、IRS 等外部連結）
- **行銷內容生成**：由 GPT-5 驅動，生成可直接複製貼上的 LinkedIn / X 貼文
- **管理後台**：查看使用者數量、積分狀況，並可發放免費積分

## 進階功能展示

- **Fork 功能**：將現有對話摘要後建立分支，在保留原版的同時開發新方向
- **付費升級流程**：一個 prompt 即加入 Stripe 沙箱付費頁面（含信用點數方案與 FAQ）
- **上下文視窗滿載後的 Fork**：自動摘要並建立新 session，維持對話記憶連貫性
- **Prompt 功能建構器**：輸入簡單 to-do list，自動轉成詳細 prompt，再用同一平台建立 app
- **登陸頁面生成**：一個 prompt 自動生成完整行銷登陸頁，包含標題、四步驟說明、見證區塊

## 部署

- 按下 Deploy，系統執行自動程式碼審查並偵測部署阻礙
- 部署約需 5~7 分鐘，完成後取得公開網址
- 需連接真實 Stripe 帳號（步驟：取得 API 金鑰 → 填入 Emergent）

## 定價方案

- 免費方案：提供基本積分試用
- 標準方案：17 美元/月，100 積分/月（可加購積分）
- Pro 方案：更多月度積分（750）、100 萬 token 上下文視窗、Ultra Thinking 模型
