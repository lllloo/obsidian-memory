## 使用情境：為不認識的商家建立 AI Agent

- 示範對象：芝加哥一間音樂場館，官網仍以傳統方式展示活動資訊
- 目標：建立可協助查詢活動、購票、場地資訊的 AI 客服 agent，並以影片形式寄給對方推銷
- 商業模式：尋找可受益於 AI agent 的網站 → 主動建立示範版本 → 聯絡業主報價

## 使用平台：Chatbase

- 使用 2.5 年，是目前最簡易的 AI agent 建立平台，不需技術背景
- 支援爬取任意網站（約 10 秒爬取 58 個頁面），自動整合知識庫

## 建立流程

1. **知識庫設定**：輸入網站 URL 自動爬取，可手動排除或新增特定頁面；也可上傳 PDF、Word 文件、文字片段、Q&A
2. **客製化外觀**：修改 agent 名稱、深色/淺色模式、品牌顏色、大頭貼（上傳 logo）
3. **選擇 AI 模型**：可選 ChatGPT 5.1（最佳品質）或 ChatGPT 4o Mini（速度較快），也支援 Claude、Gemini、Grok 等
4. **設定指令（System Prompt）**：Chatbase 根據使用情境自動生成（含角色定義、約束條件），也可自訂
5. **模型比較功能**：同一問題同時測試兩個模型，選出最佳回應
6. **知識庫持續更新**：隨時新增來源後重新訓練，自動偵測缺口並提供改善建議
7. **整合選項**：Stripe（支付管理）、Calendly（預約）等

## 部署方式

### 方式一：Chat Widget（網站角落聊天按鈕）
- 複製嵌入程式碼，貼入網站建置工具（WordPress、Squarespace 等）的嵌入區塊

### 方式二：Help Page（全頁客服體驗）
- 類似 ChatGPT 的完整聊天介面，可自訂標題、Logo、Hero 圖片
- 可生成可分享連結，無需存取對方網站

### 方式三：Lovable 快速示範頁
- 用 prompt 生成仿照對方網站風格的單頁網站並嵌入 agent
- 讓潛在客戶直接體驗，無需理解程式碼

## 知識庫品質提升

- 新增「Suggestions」功能：自動偵測知識庫中的矛盾或缺漏，主動提出改善建議
- 可將特定活動場次資訊手動新增為文字片段，確保準確度

- 免費版可試用，付費方案適合正式商業使用
