## 新功能：從其他 AI 匯入記憶

Claude 推出新功能，可將 ChatGPT 或 Gemini 的記憶匯入到 Claude，讓所有 chatbot 的個人資訊集中在同一個地方。

## 匯入步驟

1. 前往 claude.ai → Settings → Capabilities
2. 確認已開啟「Claude 可參照聊天記錄」與「從對話生成記憶」
3. 點擊「Start import」，取得一段 prompt
4. 將此 prompt 貼入 ChatGPT（或 Gemini、Grok、Microsoft Copilot 等任何有記憶功能的 chatbot）
5. 該 chatbot 會生成包含個人偏好、職業資訊、專案、常用指令等的文字檔
6. 將輸出內容複製後貼回 Claude → Add to memory

## 匯出 Claude 記憶

若想反向操作（將 Claude 的記憶匯出到其他 chatbot）：
- 在 Claude 輸入：「將你對我的所有記憶逐條列出」
- 複製輸出內容，貼入 ChatGPT 對話框讓其記憶（ChatGPT 目前不支援直接匯入，需透過對話方式）

## 記憶管理

- 點擊鉛筆圖示可編輯或要求 Claude 忘記、修正特定資訊
- Settings → Privacy → 可關閉「協助 Claude 改善模型」選項（高方案帳號仍需手動關閉）

## Claude Projects

- Projects 功能可建立主題式知識庫，設定指令與上傳文件
- 無法匯出，但可手動複製系統指令到 Claude 重建相同設定
- 與 ChatGPT Projects、Gemini Gems 功能類似

## Claude 生態系擴展

- Co-work（桌面 App）：可讀取電腦資料夾、自動建立文件，近期最常用的 AI 工具
- Claude Code（桌面 App）：建立完整 app 與網站
- Microsoft Excel/PowerPoint 整合、Chrome 擴充功能
- 行動 App 可用
