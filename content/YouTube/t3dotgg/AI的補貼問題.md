## 補貼時代正在結束

三個訊號同時出現：

- **Gemini CLI**：限制免費用戶使用 Pro 模型，加強政策違規偵測
- **GitHub Copilot Student**：取消 GPT-5.4 和 Claude Opus/Sonnet 的自選權限
- **Open Code**：被 Anthropic 律師函強制下架 Claude Max plugin

Google 率先開始縮減補貼，速度超乎預期。

## 為什麼免費推論根本不可能永續

每個 prompt 產生的費用是廣告收入的數千倍。以 Theo 的 YouTube 頻道為例：

- 每月 300 萬次觀看、465,500 小時觀看時數
- YouTube 廣告收入約 $9,000/月（$0.28/觀看）
- 一個複雜 prompt 的 API 費用可能超過 $1

廣告根本無法補貼推論費用。資料收集也不夠：資料的價值不足以覆蓋大量免費用戶的成本。

## 補貼的唯一合理目的：搶客戶

「免費推論」只有一個真正的商業目的：讓用戶試用後轉換為付費用戶。這個策略有效的前提是：**被吸引進來的用戶最終會付費**。

Theo 的用戶光譜分析：

- 「願意付費的用戶」區間：這是黃金客群，免費體驗後轉付費
- 「只能用免費的用戶」區間：永遠不會付費，消耗大量 GPU 和支援資源，是死亡陷阱
- Google 的失誤：大部分靠補貼吸引到的用戶落在第二區間

## Anthropic vs OpenAI vs Google 的策略差異

**Anthropic**：
- Claude Code Max（$200/月）可用 $5,000 算力，補貼比例從去年的 10 倍升至現在的 25 倍
- 補貼目的是把用戶鎖在自家 harness（Claude Code），阻止跳到 Cursor 等工具
- 不願與第三方工具合作，因為這樣補貼就無法換來長期用戶綁定

**OpenAI**：
- Codex CLI 給予 2x 暫時流量（為了從 Claude Code 搶用戶）
- 積極與 Open Code、T3 Code 合作，因為他們只有 30% 市場份額，策略是「讓所有選項都有，然後贏過競爭者」
- 若 OpenAI 未來佔市場 50%+，策略可能會轉為和 Anthropic 一樣封閉

**Google**：
- 沒有清晰策略，各個團隊爭搶 GPU 且互不溝通
- 免費補貼太猛，連自家 dev tools 都被擠不到 Gemini Pro 配額
- 大量免費用戶都是「永遠不會付費」的那種，現在被迫緊急縮限

## Claude Code 補貼的深層邏輯

$5,000 算力換 $200 訂閱，看起來虧本，但長期算法：

1. 重度用戶（42 歲工程師）→ 向公司推薦 → 公司訂閱整個工程團隊 → 20% 實際使用，80% 直接付費給 Anthropic
2. 隨著推論成本下降，邊際成本持續縮小
3. 大多數用戶用不到 $5,000 上限，平均補貼比 25x 少很多

## 對開發者的建議

趁補貼時代結束前，充分利用現有的 $200/月訂閱。這類高補貼方案不會永遠存在，但現在仍是使用 AI 工具的最佳性價比時機。
