## 開源的風險（反對論點）

開源確實存在真實風險，不應輕視：

- **競爭者複製**：對手可以用 AI agent 指向你的 repo，快速重建你的功能
- **自架風險**：客戶自行部署，不需要付費成為正式客戶
- **資安風險**：AI 更擅長在開源代碼中找出漏洞，Cal.com 就因此遭受大量安全報告與攻擊嘗試
- Theo 提到 T3 Chat 尚未開源，正是因為安全風險加上團隊人力不足（兩個半人）——一旦出現問題，可能瞬間損失數百萬美元

## 大型 SaaS 的護城河正在崩解

以 Salesforce 為例說明傳統大型 SaaS 的競爭結構（以下為示意數字）：

- Salesforce 有 1000 個功能，任何一個客戶只用其中 50 個（5%）
- 80% 的客戶使用同一組核心 25 個功能
- 其餘 25 個功能各自只被不到 1% 的客戶使用
- 新競爭者做完 49 個功能，客戶卻因那 1 個罕見功能而不肯遷移

這種「功能囤積」策略讓大公司牢牢鎖住客戶。但這個局面正在改變：
- Plugin 系統是舊解法，但架構複雜、支援成本高，且永遠無法覆蓋所有需求
- Vercel 的成功在於「讓你自己寫代碼」，缺少的功能用代碼補，而非 plugin

## 積木經濟（Building Block Economy）

Mitchell Hashimoto（Terraform、Ghosty 作者）提出的觀察：

- Ghosty 用 18 個月累積 100 萬日活
- libghosty（底層 terminal binding library）獨立發布後，2 個月就超過 Ghosty 本身的用戶數
- 積木比應用本身更受歡迎，因為 AI agent 偏好可組合、可安裝（npm install）、有良好文件的模組化元件

AI 的偏好：
- 研究顯示 AI 在未被引導的情況下，傾向選擇開源、免費的替代方案
- 例如：推薦 Zustand（65%）而非自行實作 state management；推薦 Vercel（100%）而非手動配置 AWS

## T3 Code 的開源效應

T3 Code 的實際數據：

- 累計約 42,000 個獨立安裝
- 週活用戶約 16,000
- GitHub stars 約 9,000
- **fork 數達 1,500**——相當於週活用戶的 10%

1/10 的週活用戶已 fork 並進行客製化，這在過去從未發生過。代表性案例 Emanuel（DP Code）：
- 加入 split chat（多終端+對話橫向並排）
- 支援同時進行多個對話
- 自建 queuing system
- 加入 commands 與 plugins
- 整合類似 tmux 的多終端功能
- 加入 handoff 功能

## 為何應該開源你的商業產品

核心論點：**讓客戶自己做他們奇怪的需求**，而非公司包辦所有功能。

開源帶來的商業利益：
1. **客戶自主 R&D**：fork 的人等於在幫你做功能實驗，你可以從中挑選最好的 PR 或想法
2. **不需要支援 1% 功能**：罕見需求讓客戶自行解決，Ghosty 作者甚至設了 bot 自動拒絕功能請求，但因為可以 fork，他拒絕得心安理得
3. **AI agent 更偏好 OSS**：開源代碼讓 AI 更容易使用、整合、推薦
4. **社群凝聚力**：公開建造吸引貢獻者與社群，彼此強化

黏著度的新模式：
- 舊方法：靠功能鎖定讓用戶無法離開
- 新方法：讓用戶在你的平台上客製化，用你的後端，但前端是他們自己的 fork；一旦深度客製化，遷移成本反而更高

## PATCH.md 概念（Theo 的原創提案）

受到 `CLAUDE.md`、`agent.md`、`soul.md` 啟發，Theo 提出 **PATCH.md**：

**問題**：用戶 fork 後，上游更新造成 merge conflict，patch 失效

**解法**：每次對代碼做客製化時，除了修改代碼，同時在 `PATCH.md` 中以自然語言記錄「這個改動的意圖」。

更新流程變成：
1. Pull 最新代碼，嘗試直接套用
2. 若有衝突，按下「用 agent 解決更新」
3. Agent 讀取 `PATCH.md` 了解每個客製化的意圖，重新在新版代碼上實現
4. 失敗時告知用戶，提供背景執行 + 驗證的選項

目標：讓軟體變成「自我 fork、自我客製、自我修復 merge conflict」的狀態，讓普通人也能持續維護自己的客製化版本。

## 結語

Theo 對開源作為商業策略押了重注（「賭上了孩子的大學學費」）。核心論點：

> 軟體可塑性（malleability）在過去不重要，因為普通用戶無法修改代碼。現在 AI 讓任何人都能用自然語言新增功能，允許客製化的平台將成為贏家。
