## 重點摘要

- Claude Code 的核心優勢：用 bash 原生指令（grep、ls、find、cat）導航檔案系統，無需昂貴的 RAG pipeline
- 像開發者一樣直接操作檔案系統，相較傳統 vector database 方案更精準、成本更低
- 對結構化資料而言，這個 file-based 架構常優於 RAG
- 實際案例：公司政策查詢專案，達到 RAG 等級的準確度但省去 overhead
- 可設定 sandboxed 環境安全執行指令
- 影片對比 claude code vs cursor、opencode vs claude code，說明各自適用場景
- 可在 claude code free tier 體驗這些技巧
