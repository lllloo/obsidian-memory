## 重點摘要

- Google Antigravity 結合 Gemini 3 Pro，採用 Cursor 公開的 agent harness 原則
- Agent harness 三大核心元素：instructions（指令）、tools（工具）、user interaction patterns（互動模式）
- Plan Mode：可直接在生成的計畫上加留言，輕鬆修改方向
- Context management 策略：讓 agent 自己用 grep 找需要的檔案，不要手動 tag——保持 context 乾淨
- Rules 與 Skills：用 Anthropic 開放標準擴充 agent 能力，可動態載入專案特定 guidelines 和 skills
- 支援 TDD 工作流與 image-based prompting
- Antigravity vs Cursor：影片有詳細對比
