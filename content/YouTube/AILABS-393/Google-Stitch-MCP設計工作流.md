## 重點摘要

- Google Stitch 透過 MCP 整合 AI 設計工具工作流，可直接在 Claude Code 中生成 UI 設計
- 完整流程：安裝 → 設定 → 透過 Google AI Studio 的 Gemini 模型生成設計 → 直接輸出至 Next.js
- 設計風格偏向開發者導向的終端機美學（terminal aesthetics）
- 不需要 Stitch to Figma 匯出，直接實作程式碼更高效
- 介紹 Vercel Agent Browser：用於測試，表現優於傳統瀏覽器自動化工具
- Stitch MCP + Vercel Agent Browser CLI 測試工具組合形成完整開發流水線
