## 重點摘要

- Moonshot AI 發布 Kimi K2.5，宣稱可同時協調 100 個 sub-agents 並行運作
- 透過 Kimi Code CLI 使用，支援 agent swarm 與視覺化 agentic intelligence（可接受影片輸入並生成程式碼）
- 實測 agent swarm：將整個 UI 專案從 shadcn 遷移至 Material UI，分組處理頁面、清理未用依賴，僅使用 25% context window
- 大型程式庫下並行速度不一定更快，但對前端任務而言是 Claude Code 的平價替代方案
- 視覺模型測試：餵入 Notion 螢幕錄影後要求複製介面，自迭代後產出含 slash commands 的功能性 Notion clone
- Kimi vs Claude 對比：前端任務上具競爭力，但特定 agentic 工作流 Claude 仍領先
