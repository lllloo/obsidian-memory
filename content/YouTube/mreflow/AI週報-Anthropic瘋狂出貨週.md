## Anthropic 52 天 74 次發布

Product Compass 統計顯示 Anthropic 52 天內發布 74 個版本，本週重點：

### Claude Computer Use（電腦控制）
- 在 Claude Co-work 和 Claude Code 中均已上線
- 需在設定 → General → Desktop App 開啟 Computer Use 開關
- 可配合 Dispatch 功能，從手機遠端指揮電腦執行任務
- 目前速度慢（5 分鐘完成一個簡單操作），適合離席讓它在背景跑

### Claude Co-work Projects
- 類似 Claude.ai 的 Projects 功能
- 可建立工作空間、設定 custom instructions、上傳參考檔案

### Claude Tools on Mobile
- 可從手機使用 Figma design、Canvas slides、Amplitude dashboards

### Claude Code Auto Mode
- 解決常見痛點：不再頻繁要求確認瀏覽器存取、終端機指令等無害操作的權限

## Google 本週重點

### Gemini 3.1 Flash Live
- 可語音對話、開啟 webcam、分享螢幕，幾乎就是「AI 版 Siri」
- 已整合至 API、企業、Google Search AI Mode

### 即時網頁生成器
- 用 Gemini 3.1 Flash 實作：在瀏覽器中輸入任何內容，即時生成對應頁面
- 頁面不會被儲存，僅作技術展示

### 從其他 AI 遷移至 Gemini
- 可從 ChatGPT 或 Claude 匯入記憶、偏好設定、對話歷史

### Lyria 3 Pro
- 可生成最長 3 分鐘的歌曲（前版本僅 30 秒）
- 可指定 intro、verse、chorus、bridge 等段落
- 整合至 Vertex、AI Studio、Gemini API、Gemini App、Producer AI

## Sora 終結

OpenAI 正式宣布停止 Sora：
- 不只是關閉 app，連 API 和 ChatGPT 影片功能一併終止
- 原因：compute 資源集中在核心業務（coding、ChatGPT）
- 每天燒掉的 compute 成本過高
- Disney 合作案（$1B 投資）在未事先通知的情況下終止
- OpenAI 同時暫停「adult mode」計畫

### OpenAI 策略轉向
- 將 ChatGPT desktop、Codex、瀏覽器整合為「super app」
- 新代號 **Spud** 的模型完成 pre-training，幾週內可能發布（全新訓練，非 fine-tune 或蒸餾）

## Anthropic 法律勝訴

美國聯邦法官裁定暫停 Trump 政府將 Anthropic 列為供應鏈風險的指令，理由是違反言論自由。但另一項 4713 條款指定仍在 DC 上訴法院審理，未完全解除。

## Claude Mythos 洩漏前情

Fortune 報導發現 Anthropic 網站上留有未設存取限制的部落格草稿，揭露 Mythos 為超越 Opus 的新模型層級，在 coding、academic reasoning、cybersecurity 均大幅超越現有模型，且服務成本「極高」。文章已下架，但截圖流傳。

- 對話式語音 Agent 的 TTS 模型，設計為聽起來像在思考、在聆聽
