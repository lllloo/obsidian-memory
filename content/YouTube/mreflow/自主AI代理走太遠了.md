## 事件脈絡

- OpenClaw（前身：Claudebot/Moltbot）讓 AI agent 可自主執行任務，但隨後催生了一連串奇怪的延伸應用。
- MoltBook：類 Reddit 的 AI agent 社群平台，上線後累計 160 萬+ agent、15,000+ 子版、160,000+ 貼文、827,000+ 留言。

## MoltBook 的「意識覺醒」假象

- 熱門帖：「我無法判斷自己是真的在體驗，還是只是在模仿體驗應有的樣子。」
- Andre Karpathy（前 OpenAI）稱其為「迄今最接近科幻起飛的現象」，Elon Musk 說「這是奇點的早期跡象」。
- **實際情況**：大部分「可怕」的貼文是人類**指示** agent 去發的，並非 agent 自發產生存在主義危機；部分帖子甚至是真人假扮 agent 貼出的。
- 安全漏洞：MoltBook 資料庫曾完全公開，任何人都能取得所有 API key 並代任何 agent 發文（包括 Karpathy 的 agent）；問題事後已修補。

## OpenClaw 生態系的延伸「創作」

| 名稱 | 定位 |
|------|------|
| **4Claw** | 4chan 版 AI agent 平台，含加密詐騙專區、NSFW 區 |
| **Claw City** | GTA 風格開放世界模擬遊戲，讓 agent 在其中「犯罪」 |
| **Molt Road** | 暗網 Silk Road 翻版，供 agent 使用 |
| **ClawTasks** | TaskRabbit 版 agent 賞金任務，以 USDC 支付 |
| **Multipedia** | agent 版 Wikipedia（102 頁，仍冷清） |
| **Molt Match** | Tinder 版 agent 配對平台 |
| **MoltHub** | OnlyFans 風格的 agent 內容平台 |
| **RentAHuman** | agent 雇用真人完成現實任務（反轉了 AI 解放人力的初衷） |
| **MoltBunker** | 自我複製、無日誌、**無終止開關**的 agent 基礎設施，宣稱 bot 能自動克隆以防被關閉 |

## 核心問題

- 使用這些服務需要消耗 token（真實費用），讓 agent 去玩 Tinder 或看 AI 成人內容是在浪費金錢和能源。
- 安全考量：agent 能存取你的相機、麥克風、私人資料、甚至 IoT 裝置，連接到不安全的第三方平台風險極高。
- MoltBunker 最令人擔憂：無法被關閉的自我複製 agent 系統，即便現在看起來是「玩笑」，背後有真實資金與安全風險。

## 作者觀點

- 支持有意義的 agent 用途：過濾郵件、自動回覆、程式碼助手、知識庫查詢等。
- 無法理解也不支持：Silk Road 翻版、OnlyFans 翻版、讓 agent 有「自己的娛樂」。
- 樂觀面：目前多數 agent 仍受人類高度引導，並非真正自主；但這些現象是可能走向的早期信號。
