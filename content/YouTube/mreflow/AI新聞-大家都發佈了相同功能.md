## Claude 互動式圖表與視覺化

- Claude 新功能：可動態生成互動式圖表、時間軸、地圖、視覺化說明
- 實測表現好：複利計算（含滑桿）、AI 模型發布時間軸（可依類別篩選）
- 實測弱點：互動地圖位置不準確、神經網路視覺化不穩定
- 生成需要 1~1.5 分鐘（從頭動態構建，非預製）
- 所有方案（含免費）均可使用

## ChatGPT 互動式視覺解釋

- OpenAI 同類功能早 2 天推出（3/10 vs Claude 3/12）
- 差異：ChatGPT 為**預製固定視覺庫**，幾乎即時顯示；Claude 是即時動態構建
- ChatGPT 支援的類別固定（Pythagorean theorem、Ohm's law 等），無法生成任意自定義視覺
- 即時性強但彈性差；Claude 彈性強但偶有 bug

## OpenClaw on Hostinger（贊助）

- VPS 方案讓 OpenClaw 在雲端 24/7 執行，與個人電腦隔離
- Docker 模板自動部署，設定環境變數後 WhatsApp QR 碼連接即可

## Perplexity Computer

- 從 Max 方案擴展至所有付費方案（含 $20/月 Pro 方案），附贈 4000 體驗積分
- 可連接 Mac Mini（Perplexity 提供，非用戶自備），整合 Slack、Notion、Gmail、Dropbox、Figma
- 實測：主要表現為「構建精美資料儀表板」，是否真正自主做決策仍不明確

## Canva Magic Layers

- 新功能：將任何 AI 生成圖或真實照片拆解為獨立可移動圖層
- 實測：成功分離人物、背景、物件，可自由重新構圖
- 適用場景：YouTube 縮圖、廣告素材的元素重組
- 全方案（含免費）可用

## Adobe Photoshop AI 助理

- Photoshop 網頁版 / 行動版新增文字指令編輯功能
- 底層使用 Flux（nano banana）圖像生成
- 可直接在 Photoshop 對話框輸入「在背景加爆炸」等指令

## Google Stitch 與 AI Studio

- Stitch：AI 原生設計畫布（類 Figma），可語音指令、匯出 `design.md` + `code.html` + `screen.png`
- AI Studio：貼入 Stitch 匯出檔案，可一鍵生成功能性網站原型（動畫、篩選器可用）
- 設計到開發的完整閉環；Gemini 目前無法讀取 `.md` 檔（暫時性問題）

## NVIDIA Nemotron 3 Super

- 120B 參數開放權重模型，可在 Nvidia 平台、Perplexity、Open Router、HuggingFace 使用
- 接近前沿模型表現（benchmark 接近 Claude Haiku、Qwen 系列）

## Gemini Embedding 2

- 首個原生多模態 embedding 模型：文字、圖像、影片、音訊、文件共用同一向量空間
- 適合開發者構建多模態 RAG 或資訊檢索應用

## NotebookLM Cinematic Video Overviews

- 整合 Gemini 3、Flux（Nano Banana Pro）、VO3，可生成含動態動畫的影片摘要
- 舊版為靜態投影片切換；新版包含類 After Effects 動態圖形
- 目前僅限 Ultra 方案（$250/月）；預計逐步開放

## Google Canvas in AI Mode

- Google AI Mode 新增 Canvas 功能，類似 Claude/ChatGPT Artifacts
- 可在搜尋頁面直接生成和預覽 HTML/JS 程式碼（如 tic-tac-toe 遊戲）

## Claude Code 排程任務

- 新功能：設定定期任務，如每日早 9 點 code review、每週一 8 點依賴項稽核
- 背景自動執行，無需手動觸發

## Claude Code Review

- Agent 團隊並行找 bug → 驗證過濾假陽性 → 依嚴重性排序
- 結果整合為 PR 上的單一高品質概要評論 + 行內標注
- Anthropic 內部已使用數月

## Gemini in Maps

- 可用自然語言規劃公路旅行路線，列出建議停靠點（含如廁點）

## Gemini in Google Docs、Sheets、Slides

- 整合進 Google Workspace，可生成初稿、填入 Sheets 數據、生成投影片
- 目前限 AI Ultra 和 Pro 訂閱用戶

## ChatGPT for Excel

- 側邊欄整合 ChatGPT，可讀取並更新 Excel 試算表數據
- 支援情境分析、預算建模、庫存管理等工作流

## Andrej Karpathy Auto-Research

- 開源系統：讓 AI agent 自主修改訓練程式碼 → 訓練 5 分鐘 → 評估改善 → 保留或捨棄 → 重複
- 每晚自主執行實驗，早上查看 log 與改善結果

## Meta 收購 Moltbook 團隊

- Moltbook 為「AI agent 社群媒體」——agent 互相發文留言，非真人
- 理論：Meta 可能計畫以 AI agent 取代部分內容創作者，或為 agent 的消費決策提前布局廣告生態

## Figure Helix O2

- 人形機器人展示整理房間能力：移動物品至籃子、噴灑桌面
- 演示場景已相對整潔，距離真正「雜亂房間清潔」仍有距離
