## 事件時間軸

- 2025 年 11 月：Peter Steinberger 以副業形式開發 **Claudebot**（後稱 OpenClaw）——將 WhatsApp 連接至 Claude Code，讓 AI agent 幫他管理信箱、訂位、入住航班、控制智慧家居。
- 專案開源後幾千顆 GitHub 星，低調運行，直到 2026 年 1 月爆發：一週 200 萬訪客、201,000 顆 GitHub 星，成為 GitHub 歷史上成長最快的開源專案。
- 專案帶動整個生態系誕生：MoltBook（AI agent 社群平台）、Silk Road for AI、Tinder for AI、OnlyFans for AI……

## 改名風波（連環蝴蝶效應）

1. Anthropic 法務發信警告：Claudebot 名稱太接近 Claude 品牌。
2. Peter 改名為 **Moltbot**（致敬龍蝦主題）——改名後 10 秒內，舊帳號被加密貨幣詐騙者搶占。
3. 詐騙者在 Solana 發假幣、在 GitHub 散布惡意程式、劫持 npm 套件、Twitter 充斥垃圾訊息。
4. Peter 秘密規劃再改名，花費 10 小時如同作戰般執行「偽裝行動」，最終改名為 **OpenClaw**。

## 安全危機

- Gartner 警告企業立即封鎖 OpenClaw 流量。
- 研究人員發現逾 30,000 個 OpenClaw 實例在網路上完全公開、無任何驗證保護，暴露用戶的 Email、行事曆、Slack 憑證、API 金鑰。
- 93% 的已驗證實例存在安全漏洞；CrowdStrike 甚至發布 OpenClaw 移除工具。
- MoltBook 因資料庫設定錯誤洩漏 150 萬組 API 金鑰與 35,000 個用戶 Email。

## Peter Steinberger 是誰

- 曾創辦 PSPDFKit（PDF 工具包），被 Apple、Dropbox、SAP 採用，近十億人使用的 App 背後有他的程式碼。
- 自力更生的多次創業成功者；退出後離開科技業三年，2025 年 4 月因 AI coding 工具重回開發圈。
- 花費每月 $10,000–$20,000 自掏腰包維運 OpenClaw。

## 為何選擇加入 OpenAI

- Meta、Microsoft、以及多家公司都有接觸；Zuckerberg 有興趣、Satya Nadella 親自來電。
- Peter 選擇 OpenAI 的關鍵理由：OpenAI 承諾讓 OpenClaw 繼續作為開源基金會專案存在；其他公司意願不明。

## 對 AI 產業的意涵

- **市場格局**：OpenAI 企業 LLM 市占從 2023 年的 50% 跌至 2025 年底的 25%，Anthropic 達 40%——主因是 Claude Code 的成功（上線 6 個月達 10 億美元營收）。
- **真正的戰場**：各家模型能力趨同，競爭焦點已轉移到「agent 層」——誰能構建讓 AI 真正代替人類行動、且安全可靠的軟體層。
- **Anthropic 的代價**：發出商標信的連鎖效應，最終讓競爭對手獲得最熱門的 agent 生態系及其創始人。
- OpenClaw 的主要用戶本來是使用 Anthropic API 的人——OpenAI 等於挖走了大量向競爭對手付費的用戶。
- 下一步：OpenAI 預計將 agent 功能深度整合進 ChatGPT，目標是「連媽媽都能用的 AI agent」。
