## Claude Cowork 上線
- Anthropic 推出 Claude Cowork：讓非開發者也能使用 Claude Code 的能力，授予特定資料夾存取權後，可自動完成電腦上的任務。
- 示範功能：整理下載資料夾、整合行事曆與會議摘要、自動建立每日代辦清單。
- 初期限定 Mac + Claude Max 方案（$100/月起），後續擴展至 $20/月 方案與 Windows。
- 本質是在背景執行 bash 指令，可完全免人工操作。

## 實測 Claude Cowork
- 請它整理下載資料夾：它掃描約 270 個檔案，建議建立 10 個分類資料夾、移動 150 個檔案、標記 35GB 舊安裝檔待刪除。
- 確認計畫後自動執行，過程中可完全不干預，完成後生成各資料夾儲存空間摘要。

## Google Personal Intelligence
- Gemini 新功能，可連結 Gmail、Google Photos、YouTube、搜尋記錄，以及 Google Calendar 與 Drive。
- 示範：用戶不說明車款，Gemini 自動從 Google Photos 辨識出車牌與輪胎規格。
- 資料不用於模型訓練，需手動開啟（非預設）。
- 目前限美國地區、Google AI Pro/Ultra 方案，且僅支援個人帳號（不支援 Workspace 商業帳號）。

## VO 3.1 更新
- 改善 Ingredients to Video（食材轉影片）功能，新增角色一致性、場景一致性、物件重用能力。
- 首次支援 9:16 垂直輸出，可升級至 4K 解析度。
- 可在 YouTube Shorts、YouTube Create、Flow、Gemini 應用使用。

## Gemini 搜尋趨勢整合
- Google Trends 現以 Gemini 為後端，可依興趣領域自動建議相關搜尋詞彙。

## Google 購物 & 翻譯模型
- Universal Commerce Protocol：AI 搜尋結果中直接顯示購買按鈕與價格追蹤功能（尚未完全上線）。
- Translate Gemma：基於 Gemma 3 的開源翻譯模型，支援 55 種語言，可在 Kaggle/Hugging Face 下載本地執行。

## ChatGPT 翻譯工具
- ChatGPT 低調上線翻譯功能（chatgpt.com/translate），支援 50+ 語言，免費方案可用。

## AI 行業動態
- Thinking Machines 開除 CTO Barrett Zoff（不當行為），OpenAI 同日重新僱用，傳聞其為雙面間諜。
- Anthropic 收緊 Claude Max 訂閱 API 使用限制：不允許在 Claude Code 以外的 IDE（如 Open Code）使用訂閱 API key，引發社群強烈反彈。
- OpenAI 趁機宣布與 Open Code 合作，允許 Codex 訂閱用戶在 Open Code 中使用。

## 快速新聞
- **Apple x Google**：Apple 宣布與 Google 多年合作，Siri 複雜查詢將使用 Gemini 模型，無論 Android 或 iPhone 均將觸及 Gemini。
- **OpenAI x Cerebras**：OpenAI 與 Cerebras（推理晶片廠商）合作，而非選擇 Nvidia 旗下競爭對手 Grok。
- **DocuSign AI**：新增合約解析功能，自動翻譯法律條款並提示潛在風險，無需另外複製到 ChatGPT/Claude 分析。
- **GLM Image**：ZAI 推出開源圖像生成模型，支援知識整合生成，可在 GitHub/Hugging Face 下載本地執行，但品質尚未達 Nano Banana 等級。
