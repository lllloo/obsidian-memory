## Nano Banana 2
- Google DeepMind 最新圖像生成模型，品質接近 Nano Banana Pro，但生成速度快一倍。
- 可在 Gemini 應用、AI Studio、Flow、Vertex 免費使用。
- 具備搜尋基礎功能：生成圖像時自動從網路即時資訊取材，文字渲染與翻譯表現出色。
- 在 gemini.google.com 點擊「Create an image」並切換 Fast 模式即可使用。

## Perplexity Computer
- Perplexity 推出的全能 AI agent，整合研究、設計、寫程式、部署、專案管理。
- 可跨 19 個模型（GPT、Claude、Gemini、Nano Banana、VO、Grok 等）動態分配任務。
- 支援 Slack、Airtable、Calendly、ClickUp、Discord 等工具整合。
- 採雲端沙箱環境，安全性優先（對比 OpenClaw 的本地自主模式）。
- 目前僅限 Perplexity Max 訂閱者（$200/月 或 $2,000/年）。
- 示範案例：自動建置 Bloomberg terminal 風格的股票分析介面、生成 Tesla 股價動態圖。

## Microsoft Copilot Tasks
- Microsoft 推出 agent 式任務功能，功能類似 OpenClaw 與 Perplexity Computer。
- 可自動完成規律任務：整理晨間摘要、回覆重要郵件草稿、預訂行程等。
- 尚未公開，目前仍在早期測試階段。

## Cursor Agents
- Cursor 推出 agent 可控制虛擬電腦的功能，並自動錄製操作影片供用戶事後審閱。
- 可設定執行時間（3 小時、5 小時、10 小時或「直到完成」），讓 agent 在背景持續工作。
- 支援多模型切換（Opus、GPT 5.3 Codex 等），可在模型卡住時手動換模型解決問題。

## QuiverAI
- 生成 SVG 圖像的工具（圖像由程式碼構成，而非擴散模型）。
- 可複製到 HTML 網站直接使用，甚至可以加入動畫效果。
- 在 app.quiver.ai 免費試用，每次生成產出 4 張圖，初始 20 點額度。

## Anthropic/Pentagon 對立
- Anthropic 拒絕讓 Claude 用於以下兩個用途：大規模監控美國公民、全自主武器（無人類決策）。
- 五角大廈（Pete Hegseth）施壓 Anthropic，要求解除安全限制，威脅將其列為「供應鏈風險」。
- Anthropic CEO Dario Amodei 發表聲明：不論威脅為何，立場不變。
- 五角大廈同時接洽 Boeing 與 Lockheed Martin，評估對 Anthropic 的依賴程度。
- xAI（Grok）與五角大廈達成協議，同意「一切合法用途」標準，填補 Anthropic 留下的空缺。

## Anthropic/中國 AI 蒸餾事件
- DeepSeek、Moonshot AI、MiniMax 被發現透過代理伺服器與大量假帳號，對 Claude 模型進行模型蒸餾。
- Claude 發布新模型後 24 小時內，MiniMax 將近一半流量重定向至新模型以擷取能力。
- 外界批評：Anthropic 本身也曾在未獲授權的情況下爬取網路資料訓練模型，此次指控略顯諷刺。

## Claude Cowork 排程任務
- Claude Cowork 新增排程功能，可設定固定時間執行重複任務（如早報、週報、每週簡報）。
- Claude Code 桌面版新增應用程式預覽功能，可在不離開 IDE 的情況下查看執行結果。

## Claude Code Remote Control
- 新增手機遠端授權功能：agent 執行需確認的指令時，會傳送通知到手機，用戶點擊「是」即可繼續。
- 解決過去 agent 在背景執行中途停頓、等待用戶回應的痛點。

## Notion Custom Agents
- Notion 推出自訂 agent，可跨 Notion、Slack、Gmail、Calendar、Figma、Linear 及自訂 MCP 執行自動化任務。
- 可設定觸發條件，自動回覆重複問題、整理任務清單、撰寫狀態更新。

## Standard Intelligence Computer Action Model
- 新公司 Standard Intelligence 發布通用電腦操作模型，以 1,100 萬小時影片資料集訓練。
- 可探索複雜網站、完成多步驟 CAD 建模、在現實中駕駛汽車，以 30fps 運行。
- 無需人工標記截圖，直接從網路影片中無監督學習。

## Pika Labs AI Selves
- Pika Labs 推出「AI 分身」功能，創建具持久記憶的 AI 角色，可代替用戶發訊息、玩遊戲、致電家人等。
- 定位類似進階版電子雞，實際應用場景尚不明確。

## OpenAI 裝置傳言
- 傳聞 OpenAI 正計劃推出售價 $200–$300 的智慧音箱（繼鋼筆、圓盤外型傳言之後的最新說法）。

## Samsung Galaxy S26 AI 功能
- 新增虛擬試穿、AI 詐騙偵測、多物件圈選搜尋等功能。
- 新款 Galaxy Buds 內建 AI；Perplexity 將整合至 Galaxy 手機。

## Burger King AI 監控員工
- Burger King 在員工耳機中加入 AI，監控員工是否對顧客說「請」與「謝謝」。
- 監控數據可能用於員工績效評估。
