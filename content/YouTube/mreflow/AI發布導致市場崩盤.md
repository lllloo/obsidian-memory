## OpenAI Codex App
- OpenAI 發布 Codex 應用程式（有別於同週推出的 GPT 5.3 Codex 模型），定位為 coding agent 指揮中心。
- 支援多個 agent 並行執行不同專案，類似 Claude Code 的 Skills 機制。
- 提供精簡 IDE 介面（比 VS Code/Cursor 更簡單），內建 Git 整合、技能安裝、差異檢視面板。
- 免費方案可在限時期間使用 Codex App（僅限 GPT 5.3 Codex 模型）。
- 實測：同時啟動太空射擊遊戲、個人作品集網站、番茄鐘計時器三個專案，均順利完成。

## Anthropic Cowork Plugins
- Claude Cowork 新增外掛功能，支援生技研究、客服、財務、法律、行銷、銷售等行業分類外掛。
- 可連結 API、整合多個 skills，比單一 skill 更強大。
- 此消息導致科技股下跌：市場擔憂 SaaS 商業模式面臨 AI 外掛的直接威脅。

## xAI Imagine 1.0
- xAI 推出 Grok Imagine 1.0 影片模型，在 grok.com/imagine 可生成 10 秒、720p 影片，含大幅改善的音訊。
- 整體品質尚可但仍有塑料感，Grok 模型整體評價常受 Elon 因素影響而低估。

## Kling 3.0
- Kling AI 發布 3.0 模型，寫實度大幅提升，可生成 15 秒影片，具備升級後的原生音訊與唇形同步。
- 目前主要透過 API 提供，Krea.ai 平台已整合 Kling 3.0 模型選項。

## Krea Realtime App
- Krea 手機應用新增即時相機濾鏡功能：鏡頭畫面即時套用 AI 風格（線框、火焰、水下等）。
- 可輸入自訂提示詞即時更換風格，互動性強。

## Ideogram 提示詞圖片編輯
- Ideogram 推出免費的提示詞式圖片編輯：上傳圖片後用文字指令修改特定元素（如帽子、背景、配件）。
- 每次編輯約 20–30 秒，支援連續迭代修改。

## Claude Opus 4.6
- 本週最新旗艦模型，專精於程式碼與 agentic 任務，支援擴展思考模式。
- 已在 claude.ai 網頁版、Claude Code、Claude Cowork 全面上線。

## GPT-5.3-Codex
- OpenAI 與 Claude Opus 4.6 相差 15 分鐘發布，同樣專注於程式碼與 agentic 任務。
- 有人用 Opus 4.6 + GPT 5.3 Codex 在 1 小時內 vibe code 出可飛行的 3D 城市飛行模擬器。

## MoltBook
- 一個僅供 AI agents 使用的「社群平台」（類似 Reddit），人類設定 agent 後讓其自主發文互動。
- 引發「AI 是否有意識」的恐慌，但實際上是用戶刻意指示 agent 說出讓人毛骨悚然的話。
- 後被發現存在嚴重安全漏洞（API key 洩漏），相關問題已陸續修補。

## OpenAI Frontier
- 企業級 AI agent 管理平台，可連接資料倉庫、CRM、工單系統，讓多個 agent 共享機構知識。
- 定位為企業 agent 部署與管理工具，非一般消費者使用。

## Perplexity 更新
- **Deep Research** 升級：在基準測試中超越 Gemini Deep Research，成為最強深度研究 agent，限 Max 訂閱者（$200/月）。
- **Model Council**：單一查詢同時調用 Claude Opus 4.6、GPT 5.2、Gemini 3.0，由合成模型整合三方結果，標示分歧點，限 Max 訂閱者。

## ElevenLabs Eleven v3
- 新版 TTS 模型，72% 用戶偏好新版；改善電話號碼、貨幣、化學式、比賽比分的語音朗讀準確性。

## Mistral Voxtral Transcribe 2
- 開源語音轉文字模型，可在裝置端執行，成本極低，類似 OpenAI Whisper 的替代方案。

## Roblox Cube Foundation Model
- Roblox 推出 4D 生成模型，可用自然語言生成 Roblox 世界中的場景、資產、動畫與程式碼（尚未開放使用）。

## SpaceX 與 xAI 合併
- Elon Musk 將 SpaceX 與 xAI 合併，構想在太空建置資料中心，利用太陽能 24/7 供電，不佔地球空間與水源。
- 工程挑戰（散熱等）仍待解決，短期實現可能性存疑。

## Anthropic vs OpenAI 廣告戰
- Anthropic 在 Super Bowl 播出廣告，模擬 AI 在對話中插播廣告，結尾標語「廣告正在入侵 AI，但 Claude 不會」。
- OpenAI Sam Altman 公開回應批評廣告不誠實，導致回應本身獲得 930 萬次觀看（廣告本身僅 410 萬次）。
