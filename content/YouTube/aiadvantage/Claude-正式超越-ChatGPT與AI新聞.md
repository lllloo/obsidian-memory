## Claudebot / Maltbot

一名開發者開源了一個能控制電腦的 AI bot，起名 Claudebot，後收到 Anthropic 的停止令（名稱太相似），改名 Maltbot。本質上是「帶著電腦的 ChatGPT」：連接 Telegram、郵件 app、整個電腦與瀏覽器，並能排程任務。問題在於粗糙、容易被 Gmail 和 X 封號，但做了許多大公司基於安全考量不敢做的事。相關深度評測另有獨立影片。

## Pencil for Claude Code

一個互動式畫布工具，在背景執行 Claude Code，提供拖放介面而非僅預覽生成的 app。可能是 Claude Cowork 與 Claude Code 的下一步演化方向。

## Claude Connectors 大升級

Claude 的 connectors 全面升級，現在直接將外部 App 介面帶入對話中（類似 ChatGPT Apps）。

**使用方式**：設定 → Connectors → 瀏覽 Connectors

**實用案例（以 Gamma 為例）**：
- 在 Claude 內啟動工作流程（思考、腦力激盪、準備內容）
- 說「用 Gamma 建立一份關於 XXX 的簡報」
- Gamma connector 直接生成，可在 Claude 內預覽並編輯
- 重點：適合**啟動工作流程**，後續細節調整仍在 App 本身更有效率

**其他應用**：連接 Slack 可用於結束工作流程（發送總結）；各 connector 功能不同

## Claude for Excel

- 以 Excel 擴充功能形式推出，Pro 方案（$20/月）可用
- 取代過去 Excel 進階用戶依賴 Visual Basic 完成的操作
- 直接用對話操控試算表

**整體方向**：Claude 正在串連「瀏覽器遠端控制 + Excel 遠端控制 + 所有 App connector」，搭配既有的優質助手介面，逐步實現 Claudebot/Maltbot 所展示的能力，但更安全可靠。

## Claude 免費方案新功能

- 免費用戶現可建立 Excel、PowerPoint、Markdown、Word 等可下載文件
- Skills 功能開放免費版：將成功的操作流程打包成 Skill，之後可重複使用

## Google Agentic Vision（快報）

- Gemini 免費 Flash 新功能：用程式碼深度分析圖片
- 示範：分析六根手指的圖片，用 code 畫框、計數後得出正確結論
- 應用潛力：管線分析、圖片放大追蹤等（類似電影裡的 AI 放大鏡）
- 備注：OpenAI GPT-o3 之前也有類似功能，之後被移除
