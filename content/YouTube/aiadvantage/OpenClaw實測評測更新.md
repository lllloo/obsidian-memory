## OpenClaw 是什麼

OpenClaw（前身為 Clawbot）是開源的個人 AI Agent 系統——一個擁有完整電腦、瀏覽器與各種工具存取權限的 AI，能夠端對端自主完成任務，不需要人介入每一個步驟。

這不是「輔助型 AI」，而是第一個作者認為真正能用的「個人 AI 助理」。

## AI 的五個層次

理解 OpenClaw 的意義，需要先定位它在 AI 應用光譜的位置：

1. **日常問答**：把 AI 當 Google 用，寫 email、基本任務
2. **日常工作**：Prompt 工程、Projects/GPTs、生產力提升 20-30%
3. **原型製作**：Vibe coding，快速將想法視覺化
4. **建構應用**：做出真正能執行功能的 App，但仍需人操作
5. **個人 AI Agent**（OpenClaw 所在）：AI 有自己的電腦、瀏覽器、帳號，自主行動，人只看結果

前四層都需要人的輸入；第五層是真正的「讓它去做，你看結果」。

## 什麼真正有效

作者從初期「沒什麼了不起」的評價，徹底翻轉為「這改變了我的工作觀」，關鍵在於找到讓它發揮的方法。

**核心學習：給足夠多的脈絡（Context）**

作者在讓 OpenClaw 執行任何任務之前，先餵給它：
- 十多個 Markdown 檔案，涵蓋個人資料、公司運作、工作流程、個人願景
- 過去 40 支 YouTube 影片的逐字稿
- 研究資料庫（哪些故事被選入影片、如何被呈現）

讓它先「浸泡」在所有背景資料中，才開始賦予任務。

**模型選擇：Opus 4.6（API）**

作者強調只有 Opus 4.6 通過 API 使用才能發揮完整效果——提供 100 萬 token 的 context window。代價是費用高昂（作者曾單日花費 $300 美元在 Opus API 費用上）。透過 Claude 帳號訂閱的版本 context window 較小，效果有差距。

**工具配置**

- Notion 帳號（API 直連，不透過瀏覽器操控）
- 專用 email（使用 Agent Mail 服務，Google 帳號容易被封鎖）
- Brave Search API（瀏覽器之外的搜尋能力）
- 瀏覽器 + OpenClaw 擴充套件（完整控制瀏覽器）
- Telegram 連接（可從手機遠端控制）

**實際成果範例**

自動化「下午掃描」cron job：
1. 掃描所有長期追蹤的 AI 新聞來源
2. 比對過去幾年影片資料庫，篩選出作者會報導的故事類型
3. 發 email 給研究負責人 Danielle
4. 更新 Notion 研究資料庫
5. 為每則故事生成 10 張 B-roll 圖片供剪輯使用

完全自動、穩定、可靠——不只是「自動化」，而是智慧型的篩選與判斷。

## 問題與限制

對多數人而言，這仍然是非常困難的選項：

- **設定流程**：需透過 terminal，沒有技術背景很難上手
- **安全性**：基本上不安全，不論做了多少防護，AI 仍連接在你的網路上且與你的服務有接觸點
- **先決知識**：需要理解 sub-agent、context window 邊界、Markdown 格式、記憶存取方式等概念
- **穩定性**：連結特定 API（如 Google Drive）仍有困難

**作者建議**：對 99.9% 的人而言，這是值得旁觀了解、但不建議自己動手的東西。若要嘗試，以「探索與學習」為目標，而非期待立刻節省時間。

## 展望

OpenClaw 的出現，讓多個趨勢加速：

- ChatGPT、Claude、Gemini 都會往這個方向演進，目標是更易用的消費者版本
- 各方開始為此架構開發「Skills」（可插拔能力模組）
- 知識型、數位化的工作，已有業者估計 10-30% 的任務可端對端交給 Agent 執行

對知識工作者而言，「工作被補充」正在轉向「工作被端對端取代」——至少在部分任務上，這個時刻已經到來。
