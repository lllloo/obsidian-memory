## Claude 免費方案大升級

Claude 近期持續發布對消費者有實際價值的功能，本週延續這個節奏，有兩大重點：

**免費方案新增功能**：
- 在免費層建立 Microsoft Office 文件（Excel、Word），Claude 在此項目上本來就是業界頂尖
- 連接部分外部應用的 Connectors
- 更完整的自訂指令設定能力

**對比 ChatGPT**：ChatGPT 免費版開始顯示廣告，而 Claude 免費版功能不斷增加且無廣告，在產品競爭力上明顯領先。

## Sonnet 4.6

Claude 的 cost-efficient 旗艦模型大幅升級：
- 性能已非常接近 Opus，但成本遠低於後者
- 特別強調知識工作，尤其是建立 Word 文件與 Excel 試算表
- 免費方案用戶也可使用升級後的 Sonnet 4.6

若還沒試過 Claude，現在是最好的時機，尤其是文件類工作用戶。

## Google Docs AI 語音摘要

Google 將 NotebookLM 的語音摘要功能（將文件轉成 Podcast）引入 Google Docs：在 Docs 中點選「工具 → 語音摘要」，可將文件轉為語音，不用自己讀。

注意：功能尚未全面開放，部分帳號仍未出現。

## OpenAI 本週動態

- **廣告上線**：僅限免費與 $8 方案，付費方案不受影響
- **GPT-5.3 Codex Spark**：程式碼專用模型，效率提升，但對多數用戶無直接影響
- **Legacy 模型下架**：GPT-4.0、4.1 等舊模型從介面移除，介面精簡化
- **理論物理新發現**：GPT-5.2 推導出一個被驗證的理論物理新結果（附官方部落格文章）
- **收購 OpenClaw 創辦人**：OpenAI 挖角了 OpenClaw 的建立者 Peter Steinberger

## 三款中國 AI 新模型

本週三個中國模型值得注意：

| 模型 | 特點 |
|------|------|
| Qwen 3.5 | 宣稱性能超越 GPT-5.2 和 Gemini 3 Pro，售價為前者的三分之一 |
| MiniMax M2.5 | Agentic 任務性能接近 Opus 4.6 或 GPT-5.2 |
| Seed 2.0（ByteDance）| 性能接近 GPT-5.2，但售價僅約十分之一 |

意義：中國模型的出現大幅降低 Agent 實驗的成本門檻，不再需要每天花費 $100-300 美元跑 Opus API。

## OpenClaw 替代方案

對 OpenClaw（功能強大但設定複雜、有安全疑慮）感興趣但又不想親自動手的用戶，有以下選項：

- **Manus AI**：消費者友善版本，有用戶日常使用反映良好
- **Kimclaw**：中國版本的 OpenClaw 易用化部署
- **Claude Cowork**：官方版本，安全性更高、介面更友善，且現已支援 Windows（此前僅 Mac）

Claude Cowork 的使用案例基本上也適用於 Manus 和 Kimclaw。
