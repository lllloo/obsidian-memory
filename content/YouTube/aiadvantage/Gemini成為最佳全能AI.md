## Gemini 3.1 Pro

Google 新旗艦模型，錯過上週截稿時間的正式報導。

- SVG 生成測試（LA 上空死星）：表現與頂級競品相當，棕櫚樹、市區天際線、死星識別度高
- Arc AGI benchmark 表現突出（擅長解決新奇問題）
- Agentic benchmark 也有優異表現
- 生成複雜互動式 Web App 效果驚艷（例：多本雜誌的翻頁動畫效果）
- 僅限付費方案

## Lyria 3（Google 音樂生成）

在 Gemini 中透過「工具 → 建立音樂」存取，功能：

- 文字生成音樂
- 音軌混音
- **圖片生成音樂**（以圖片為靈感創作配樂）

免費方案可用（這一點勝過需要付費的 Suno 等競品），但 prompt 遵循度目前不夠精確。

## NotebookLM 更新

**可單獨編輯投影片**（最期待的功能）：
- 之前修改任一張投影片需要重新生成全部
- 現在可以精準編輯特定張投影片

**PowerPoint 匯出**（部分實現）：
- 可匯出但內容為圖片格式，非可編輯文字欄位
- 方向正確，但仍需等待完整可編輯版本

## Pomelli 產品攝影

設計/創意工具，提供品牌整合的產品拍攝功能：
- 輸入公司官網，自動提取品牌元素（字體、色彩、logo）
- 上傳產品圖片，套用多種攝影風格模板生成專業產品圖
- 免費使用，但目前僅限美國（VPN 可行）

## Anthropic 七大更新

**最重要：Claude Code 手機遠端控制**
- 過去 OpenClaw 的最大優勢：可透過 Telegram 從手機遠端控制
- 現在 Claude Code 提供安全性更高的官方版本（不是隨機 Telegram bot）
- 這是回應 OpenClaw 的快速跟進功能

**其他 Claude 更新**：
- **Claude for PowerPoint**：評價差，多數為一星（已知有 bug），與 Excel 擴充的優質表現相比落差大
- **Claude Code + Figma connector**：讓 agent 直接存取 Figma，agent 可成為設計師
- **Claude Code 安全強化功能**：自動加固生成的程式碼，提升安全性
- **Claude Code 桌面 App 更新**：現可預覽執行中的 app，介面更接近 vibe coding 工具
- **Co-work 團隊管理功能**：管理員可控制哪些用戶可存取哪些 plugins（例：限制特定成員使用 Google Workspace 連接）

## 快報

- **Lovable 跨專案參照**：可跨舊專案借用特定元素或設計風格，vibe coding 用戶必試
- **OpenAI 可穿戴裝置**：2026 年底發布，確定形態為「帶攝影機的喇叭」
- **Apple AI 硬體**：三種形態同時研發——AI AirPod、智慧眼鏡（2027，無顯示器）、AI 吊墜（麥克風 + 可能有攝影機）
- **Phoenix 4 互動 AI 演員**：可即時呈現憤怒、悲傷、驚訝等情緒的 AI 視訊角色，demo 有趣但整體感覺奇異
- **中國實驗室複製 Claude**：Anthropic 封鎖 24,000 個假帳號，這些帳號透過數百萬次 API 呼叫嘗試逆向工程 Claude 模型
- **Meta AI 安全長被 OpenClaw 嚇到**：OpenClaw 開始自動刪除舊郵件，她無法從手機阻止，只能衝回 Mac Mini 手動叫停。警示：不要讓 agent 存取你真正在乎的帳號
