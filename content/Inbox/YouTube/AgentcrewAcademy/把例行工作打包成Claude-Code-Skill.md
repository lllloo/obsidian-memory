## Skill 是什麼

Skill 是一本封裝好的提示詞、工作手冊。可以放：

- 專家知識
- 檢驗標準
- 已經跑熟跑穩、希望未來自動化的工作流

### 結構

- **主檔 `skill.md`**：給模型讀，不是給人讀。告訴模型他要做什麼任務、是什麼角色、流程每一步是什麼
- **副檔**：特定情況才需要的細節、檔案、腳本，主檔建立索引連到副檔，模型按需載入

### 觸發方式

| 方式      | 說明                                                                |
| --------- | ------------------------------------------------------------------- |
| 手動觸發  | 打 `/` 加上 skill 名字                                              |
| 自動觸發  | 模型讀到主檔開頭描述，判斷有需要時自動啟動（所以描述寫得清楚很重要） |

## 把例行工作 Skill 化的示範

講者是 GMAT 老師，有一個多語言的教學 blog，希望把 blog 內容拿到國外論壇回覆網友引流。沒有 AI 之前每天 3-4 篇要花 30 分鐘到 1 小時——找文章、思考可引用的內容、組織回覆。

### 跑通工作流的步驟

#### 1. 找到 MCP 工具

問 Claude Code「有沒有 MCP 可以幫我讀取 Reddit 的文章跟回覆」並安裝對應 MCP。MCP 是封裝好的工具組，讓 Claude Code 跟特定服務交換資訊。

#### 2. 抓貼文

> 「請幫我找過去一週內值得我用我的教學專業回覆的學員考生求助貼，幫我找 3 篇」

Claude Code 一次找 30 篇、20 篇、新文章、熱門文章——電腦對電腦溝通可以快速大量處理，不像人類要一篇篇看。

#### 3. 用個人知識庫擬草稿

把過去所有講義、課程、文章、影片、答疑整合成一個資料夾「第二大腦」：

> 「請查詢我的知識庫，幫我擬定回覆他們的草稿，用英文回覆」

讓 Claude Code 不寫四平八穩的通用回答，而是符合自己教學觀念的回答。

#### 4. 修飾風格——使用第三方 skill

第一版草稿太長、太列點、太「AI 味」。安裝網路上的「去 AI 味」skill：

- 把 skill 連結丟給 Claude Code，請他裝進來
- 用 `/<skill-name>` 觸發
- Skill 教 AI 調整句長、用詞等級、標點符號習慣

#### 5. 置入 blog 連結

在資料夾放部落格文章索引：

> 「我的資料夾裡有 blog 文章的索引，幫我判斷這 3 篇文章分別適合置入什麼連結」

Claude Code 讀索引做語意配對，自動嵌入連結。

#### 6. 複製到剪貼簿（手動發文）

> 「幫我複製到剪貼簿，要 Markdown 格式」

純文字格式不會帶連結，Markdown 格式才會。最後手動貼到 Reddit 發文——不用 MCP 自動發是為了避免被網站視為垃圾訊息鎖帳號。

## 包成 Skill

跑通整個閉環後，跟 Claude 講：

> 「幫我把這個對話中我們的工作流包成一個 skill，名字叫 reddit-demo」

也可以下載 `skill-creator` skill 幫忙寫出更好的 skill 結構。

### Skill 內容

| 步驟  | 內容                                          |
| ----- | --------------------------------------------- |
| 1     | 載入工具                                      |
| 2     | 抓取貼文                                      |
| 3     | 篩選——什麼樣值得回答、什麼樣不值得（聰明的決策邏輯） |
| 4     | 查詢知識庫（路徑寫死，AI 不會走錯路）          |
| 5     | 擬出英文草稿                                  |
| 6     | 去 AI 味                                      |
| 7     | 找對應 blog 連結                              |
| 8     | 輸出最終草稿、複製到剪貼簿                    |

## Skill 重跑的效果

清空對話模擬隔天起床，直接 `/reddit-demo`：

- 自動執行每一步
- 自動辨認可以同時進行的步驟並行處理
- 中間只需要在關鍵節點按 OK 確認
- 過程中產生太長停下來時主動跟你講「繼續」即可
- 最後自動複製到剪貼簿

整個流程使用者不再像第一次那樣帶著走，AI 自己跑完。

## 核心心法

> 「先學會跟 Claude Code 協作，手把手帶他一步一步做完你日常的工作，做到滿意之後，跟他講請你幫我把這個對話 session 裡面的工作流包成一個 skill。」

不需要學寫 skill 的程式碼，只需要：

1. 帶 Claude 跑通一次
2. 跑通後請他打包
3. 未來 `/<skill-name>` 直接執行

每個人的專欄都會累積成一系列自己的 skill，包含：

- 專業手冊（如答覆學生問題前要先查知識庫 + 對話記錄 + 學生資料）
- 工作流（家教面談前整合成績單與背景產出摘要、學員客戶跟進與追蹤流程）

把日常工作 skill 化 = 把工作的 90% 時間省下來。
