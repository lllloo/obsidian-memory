## 三種協作距離

依任務風險與時間敏感度，選擇與 Claude Code 的協作模式：

- **全程盯梢**：每一步都盯著輸出，發現走偏立即中斷
- **排隊介入**：任務方向沒問題，但臨時想到下一步要追加
- **完全放手**：明顯耗時的任務丟到背景跑，自己去做別的

決策標準：任務是否在你預想範圍內？風險高不高？時間能不能等？

## 全程盯梢與及時中斷

- 場景：眼睛盯著每條輸出，發現方向跑偏要立刻喊停
- 操作：按一次 `Esc`（Escape）→ 切斷當前步驟，控制權交回給你，可直接打字給新方向
- 操作：連按兩次 `Esc` → 啟動倒帶功能（rewind），可回到之前任意一輪對話重新指示，等於「上一句沒講過」
- 適用情境：發現指令下錯了，不需要解釋或道歉，直接回到那個指令重下即可
- 比喻：家長坐在小孩旁邊看寫作業，看到寫偏立即喊停重寫

## 排隊介入（追加指令）

- 場景：當前任務方向 OK，但臨時想到下一步要做什麼
- 操作：直接打新訊息按 `Enter` 送出
- 行為：訊息不會打斷當前任務，會被標記為「排隊中」，等當前任務跑完自動接續處理
- 重點：沒有強迫停下，是預先把下一步排好讓他自然接過去
- 範例：請 Claude Code 整理資料夾文件時，可直接追加「下一步請做 X」

## 完全放手（背景執行）

- 場景：壓縮影片、語音轉文字、大型搜尋等明顯耗時的任務
- 觸發提示：螢幕會出現 `Ctrl+B` 快捷鍵提示
- 操作：按 `Ctrl+B` → 任務丟到背景，可同時跟主 Claude 互動做別的事
- 任務完成時會自動回傳結果，主 agent 收到後會主動報告
- Claude Code 也可能自己判斷任務適合背景執行而主動移入背景

## 背景任務的監看

- 背景跑時下方會出現 `Share` 入口，點進去可看：執行時間、目前進度、`go back` / `close`
- 也可以直接對話問「我的背景任務進度怎樣？」→ Claude 會解讀日誌回報進度（例如「處理到 15%」）

## 追加任務時的「擋手符號」

- 螢幕上有「擋手符號」標示 Claude 是否已吃到追加訊息
- 擋手在右側 → 還沒吃到，可以繼續修改追加內容
- 擋手移到左側 → 已吃進去，會在當前任務跑完後依序處理
- 多次追加會排成佇列，全部跑完才真的停下

## 背景中啟動「助手解說」

- 背景任務跑很久時，可按 `B` 鍵啟動助手
- 助手不干預任務，只負責解釋目前進度、是否卡住
- 隨時按 `Space`／`Enter`／`Esc` 關閉助手
- 若決定停止背景任務，可按方向鍵下進選單後按 `X`（stop）終止

## 範例情境

- 在 Reddit 上找關於 Claude 的 100 則發文 → 中途想改成 50 則：按 `Esc` 改字
- 同一搜尋過程中，臨時想加上「也找 OpenAI 的」→ 直接打字送出，不打斷主任務
- 拖入 600MB 影片檔請求壓縮 → 按 `Ctrl+B` 移背景，同時繼續做別的查詢

## 結論

- 三種距離各對應一個快捷鍵：`Esc`（中斷）、`Enter`（排隊）、`Ctrl+B`（背景）
- 養成這樣的協作默契，能把 Claude Code 的產能再拉一個檔次
- 重點不是工具會不會做事，而是你選對距離，避免乾等螢幕或無謂中斷
