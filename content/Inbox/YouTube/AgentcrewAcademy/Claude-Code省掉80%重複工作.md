## Claude Code 作為辦公室助手的核心概念

Claude Code 不是只有工程師能用的工具。它可以直接讀取資料夾中的混雜檔案（TXT、PDF、會議記錄、報價單等），理解意圖後自動提取、整理、產出所需文件。

關鍵原則：**意圖清楚即可，不需要一步步指定怎麼做**。告訴 Claude Code 你要做什麼、為什麼做，它會自己決定怎麼找資料、怎麼完成任務。

## 三個真實辦公場景示範

### 場景一：從混亂資料產出決策備忘錄

給定一個包含各種格式混雜檔案的資料夾（會議錄音轉錄、廠商報價、HR 資料、週報等），只需告訴 Claude Code：

> 幫我整理出一份決策備忘錄，因為明天要跟主管開會討論決策

Claude Code 會：
- 自動找到並讀取資料夾內所有相關檔案
- 辨別哪些內容與決策有關
- 整理出含背景、報價、傾向分析、決策點的備忘錄
- 主動提醒哪些事項今晚需要確認

資料夾名稱不需完全一致，Claude Code 會自己匹配找到。

### 場景二：多廠商報價比較

給定同一資料夾，改成：

> 幫我整理目前的報價，評估哪家 CP 值最高，因為明天要開報價會議

Claude Code 會區分不同廠商、不同方案的報價，自動計算 CP 值比較，輸出成獨立檔案。

### 場景三：補完未完成的週報

給定一份只填了部分資訊的週報草稿，要求：

> 根據資料夾裡的資訊，補完這份未完成的週報，另存新檔

Claude Code 能辨別哪些欄位尚未填寫，主動從資料夾抓取對應資訊補齊，包括入住率、維修回報、會員狀況、應收款等，並標注哪些資料尚不存在、在誰手上。

## 工作模式轉變

以前的模式：自己整理檔案 → 餵給 AI → 拿回來自己修改

新的模式：給 Claude Code 一個混亂的原始資料夾 + 清楚的意圖 → 它直接找檔案、做完大部分工作
