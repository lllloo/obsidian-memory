## 為什麼要學

- 從 GUI App 過渡到終端機 CLI 版本時，介面陌生、不知如何操作
- 學會基本指令與快捷鍵後，操作速度顯著提升
- 不需一次背完，遇到再回查即可

## 六個常用 slash 指令

| 指令       | 用途                                                              |
| ---------- | ----------------------------------------------------------------- |
| `/clear`   | 清空對話從零開始，釋放最大上下文空間                              |
| `/resume`  | 跳到另一串歷史對話（不同對話框）                                  |
| `/rewind`  | 在當前對話框內倒帶到之前某則訊息                                  |
| `/model`   | 切換 AI 模型，亦可調整思考預算                                    |
| `/compact` | 壓縮上下文，把前面對話濃縮成摘要釋放空間，後面可加焦點任務說明    |
| `/config`  | 開啟設定（語言、互動風格、用量檢視等）                            |

## 實用鍵盤快捷鍵

| 快捷鍵           | 用途                                                                            |
| ---------------- | ------------------------------------------------------------------------------- |
| `Enter`          | 送出訊息                                                                        |
| `Shift+Enter`    | 換行                                                                            |
| `Tab`            | 自動補全                                                                        |
| `Ctrl+U`         | 清除游標前的整行                                                                |
| `Ctrl+K`         | 清除游標後的整行                                                                |
| `Ctrl+V`         | 貼上（圖片貼上各平台一律 `Ctrl+V`，連 macOS 也是）                              |
| `Esc` 兩次       | 中斷當前動作 / 進入 rewind                                                      |
| `Ctrl+C` 兩次    | 直接退出 Claude Code 回到終端機                                                 |

## 啟動與退出

- 在資料夾內輸入 `claude` 即啟動
- 路徑導引：`cd ..` 上一層、`cd <資料夾>` 進入；不知路徑時可把資料夾拖入終端
- 看到上下兩條斜線包住的提示符 → 已進入 Claude
- 退出：連按兩次 `Ctrl+C`（一次只是清行）
- bypass permission 模式：啟動時加 `claude --dangerously-skip-permissions`，左下角會顯示「不過問模式」
- 進入後也可用 `Shift+Tab` 切換模式（plan、允許編輯等）

## Esc 一次 vs 兩次

- 一次 `Esc`：即時中斷當前任務，控制權交回給你
- 兩次 `Esc`：進入 rewind，可選擇回到對話中任意一則訊息重新指示
- 適合用兩次 Esc：方向錯了、需要回頭重新導正
- 不需要用 Esc：方向對只是想追加任務 → 直接打字按 `Enter` 排隊

## 任務排隊的擋手符號

- 追加訊息送出後，前面會有「擋手符號」
- 擋手在右側 → 訊息還未進入 Claude 任務
- 擋手在左側 → Claude 已收到追加訊息，會在當前任務告段落後接續

## /compact 與 /clear 使用時機

- 上下文長 → 額度消耗加快、模型注意力下降、後續指令理解度降低
- 任務未結束、想保留進度 → `/compact`（可附「focus 在某任務」說明）
- 任務已結束、要開新任務 → `/clear`（釋放最大上下文空間）
- 養成 compact / clear 的習慣是維持產出品質的關鍵

## /model：模型與思考預算

- 日常任務 / 文件處理 → Sonnet（額度消耗較慢，能力夠用）
- 複雜推理 / 寫程式 / 解難 bug → Opus
  - Pro 方案（20 美元）切 Opus 很快會用完額度
  - 100 美元以上方案較適合長時間使用 Opus
- 思考預算：用左右方向鍵調整，給越多越聰明但額度消耗越快
- 講者一般使用「中等思考預算」+ Sonnet
- Haiku：最快、最省、但較不聰明，適合簡單查詢與文檔總結

## /config：系統設定與用量

- 帳號狀態與目前設定一覽
- 可調整：畫面風格、溝通風格（學習型 / 解釋型 / 自訂）、語言
- 用量檢視：右切可看 5 小時 / 週視窗剩餘額度，再右切看每日使用紀錄
- 終端機操作幾乎不需滑鼠（除了滾動），全部用上下左右鍵

## 結論

- 7 個指令 + 7 個快捷鍵涵蓋絕大多數操作
- 不需一次背完，遇到問題回查即可
- 熟練後與終端機的合作能無縫接軌
