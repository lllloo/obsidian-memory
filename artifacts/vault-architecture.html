obsidian-memory 的架構

這個 vault 不是「一堆 markdown」，而是一套用資料夾編碼 agent 權限的系統：同一個 agent 在不同資料夾裡能做的事完全不同。三張圖分別畫權限邊界、三個動作、以及對外的唯一入口。

01資料流與 agent 的寫入權限

邊框樣式就是權限：粗實線＝agent 全權，虛線＝write-once（可新增、不可改），灰點線＝agent 完全不碰。

02三個動作：Ingest / Query / Lint

三者都只在 raw + wiki + schema 上跑。真正讓知識複利的是 Query 那條回存迴路——好答案不留在對話裡。

03對外的唯一入口：ask-vault

別的 repo 可以問這個 vault，但這個 vault 不會伸手進別的 repo。單向、唯讀、無常駐。
