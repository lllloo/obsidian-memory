artifacts

這個 vault 的 wiki/ 是給 agent 讀的：高密度、逐條證據標註、一段就是好幾百字。這裡放的是同一批知識改寫成人讀的版本，以及不是 markdown 的產出（架構圖、報告）。每頁都是某個時點的快照——來源 wiki 頁之後改了不會回頭同步，要更新就整頁重跑。

  • 前後端分離的測試地圖

    Vue ＋ Laravel 的測試怎麼堆。核心是「測試不是一條清單而是四個互相垂直的維度」——射程、判準來源、驗誰、執不執行程式碼；把它們排成一列才會覺得永遠有漏。六張圖含四層射程、判斷脫離框架的關鍵動作、導入順序與兩條停止條件。

  • obsidian-memory 的架構

    這個 vault 不是「一堆 markdown」，而是一套用資料夾編碼 agent 權限的系統：同一個 agent 在不同資料夾裡能做的事完全不同。三張圖畫權限邊界、三個動作（Ingest／Query／Lint），以及對外的唯一入口 ask-vault。

    2026-08-08 ｜ 來源：CLAUDE.md、schema/SYSTEM-DESIGN.md

這一層不參與系統。artifacts/ 是呈現層，不屬於 vault 的三層架構——不進 Ingest／Query／Lint，也不能當 raw/ 或 wiki/ 的來源。知識本身仍住在 wiki/，這裡的頁面畫得再好也不取代它。新頁由 /vault-page 產出並在此登錄。
