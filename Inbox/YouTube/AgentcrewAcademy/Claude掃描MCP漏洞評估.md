## 場景：想找一個玩音樂的 MCP

作者前一天看到有人用 Claude 加演算法直接寫程式播音樂，於是請 Claude 找相關 MCP。結果搜尋出一堆——能直接操作播放、現場編程音樂的都有。

## 選 MCP 的評估條件

不是看到就裝，先列出篩選條件：

- **操作穩定**
- **使用人數越多越好**——人多代表風險小，沒什麼人用的工具就像超市冷門商品讓人不安
- **團隊維護狀態是否友善**

把條件丟給 Claude，請它評估哪些符合。Claude 列出符合條件的 MCP，並回報具體數字（例：至少 39 個人在用）。

## 安裝前的安全掃描

確定要裝某個 MCP 後，請 Claude 做安全掃描（原始碼分析）：

- 掃完發現 **7 個漏洞**
- Claude 評估：這 7 個漏洞**只在把 MCP 連上公開網站才有問題**
- 本機跑不會受影響
- 原始碼沒有可疑的模式
- 沒有惡意程式碼

最後 Claude 判斷此 MCP 安全，可以裝。

## 重點

裝任何 MCP 前先做兩段檢查：

1. **使用條件評估**：穩定度、使用人數、維護狀態
2. **原始碼掃描**：找漏洞、評估漏洞的觸發情境（本機 vs 公開網路）、確認沒有惡意程式碼

漏洞數量不是直接 reject 的理由——要看實際使用場景是否會觸發。Claude 可以幫你做這層判斷。
