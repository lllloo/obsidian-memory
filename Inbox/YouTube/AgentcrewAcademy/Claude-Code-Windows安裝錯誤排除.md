## 重點摘要

這集專門處理 Windows 安裝 Claude Code 時最常見的 5 類問題：

- 安裝程式無法執行（功能無法點擊）
- Anthropic 帳號登入失敗
- 啟動後無法使用
- 網路連線問題
- 每個問題都有對應的排除步驟

**遇到「功能無法點擊」的處理方式**：點選介面中的「Reinstall」按鈕，重新下載並執行安裝程式一次，通常可以解決。
