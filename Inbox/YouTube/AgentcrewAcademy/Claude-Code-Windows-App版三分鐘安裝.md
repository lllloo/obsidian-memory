## 適用對象

- 零技術背景、不想碰終端機的學習者
- 想在 Windows 上最快用上 Claude Code 的人
- App 版（Claude desktop）是目前最容易上手的方式

## 兩個步驟總覽

整個安裝只需要兩件事：

1. 安裝 Git（Windows 版）
2. 安裝 Claude desktop App（Windows 版）

完成後 App 內就會同時看到 `code` 與 `chat` 兩個入口。

## 步驟一：安裝 Git

- 到 Git 官方網站下載 Windows 版本
- 執行下載的安裝程式，所有選項全部保留**預設值**，一路按確定即可
- 等待約 20 秒安裝完成
- 安裝完成後直接關閉視窗，後續不需要再手動操作 Git

## 步驟二：安裝 Claude desktop App

- 到 Claude 官方網站下載 Windows 版本
- 執行安裝程式，等候安裝流程跑完
- App 自動跳出代表安裝完成
- 介面會顯示 App 版本，並提供 `code` 與 `chat` 兩個功能入口
- 首次使用需連線（登入）自己的 Claude 帳號

## 重點觀念

- App 版完全不需要操作終端機，這是它對非工程師的核心價值
- Git 是 Claude Code 運作的前置依賴（即使 App 版也要先裝）
- 全程預設選項即可，不必理解每個安裝細節
